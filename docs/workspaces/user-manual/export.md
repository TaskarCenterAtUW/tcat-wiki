## Export a Workspace

This section explains how to upload a workspace as a new TDEI dataset or prepare a file for download.

_For a list of all guides on the TCAT Wiki, refer to the [Guides List](../../guides-list/index.md)._{ .guides-list-ref }

---

### Open the export page

1. **Select** a workspace from the [Dashboard](dashboard.md)
2. Open the workspace actions menu
3. **Select** the export option

The **Export Workspace** page provides **Upload to TDEI** and **Download** options.

![Workspaces Export Workspace page with Upload to TDEI and Download options](../../resources/images/workspaces/user-manual/16-export/01-export-light.avif#only-light)
![Workspaces Export Workspace page with Upload to TDEI and Download options](../../resources/images/workspaces/user-manual/16-export/01-export-dark.avif#only-dark)

---

### Upload the workspace to TDEI

1. Review the **Upload to TDEI** option
2. **Select** **Start**
3. Follow the prompts to export the workspace as a new TDEI dataset

Uploading to TDEI requires a **POC** or **osw_data_generator** role in at least one TDEI project group. If you do not have either role, Workspaces displays a permission message and provides **Go back** instead of the export form.

---

### Download workspace data

1. Review the **Download** option
2. **Select** **Start Preparing File for Download**
3. Wait while Workspaces prepares the file
4. When the button changes to **Start**, **select** it again to download the prepared file to your device

!!! note "Preparation time"

    Preparing the file may take a minute. Keep the export page open while the file is being prepared.
