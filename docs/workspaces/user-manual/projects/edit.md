## Edit a Project

This section explains how to update project details, instructions, imagery, team members, configuration, and project actions.

_For a list of all guides on the TCAT Wiki, refer to the [Guides List](../../../guides-list/index.md)._{ .guides-list-ref }

---

### Edit project settings

1. Open the project
2. **Select** the edit control next to the project name
3. Select a section from the project settings navigation
4. **Select** **Save** after making changes, or **Cancel** to leave without saving

The edit page includes **Project details**, **Instructions**, **Imagery**, **Team Members**, **Configuration**, and **Actions**.

#### Project details

The **Project details** section displays the project name and description. The project name field can be disabled with the message **Project name cannot be edited**. Update the **Project Description**, then select **Save**.

![Edit Project Project details section showing the non-editable project name, description field, and Save button](../../../resources/images/workspaces/user-manual/09-projects/12-edit/01-settings-project-details-light.avif#only-light)
![Edit Project Project details section showing the non-editable project name, description field, and Save button](../../../resources/images/workspaces/user-manual/09-projects/12-edit/01-settings-project-details-dark.avif#only-dark)

#### Instructions

Use the **Instructions** section to update **Detailed Task Instructions** in the rich-text editor, then select **Save**.

![Edit Project Instructions section showing the Detailed Task Instructions rich-text editor](../../../resources/images/workspaces/user-manual/09-projects/12-edit/02-settings-instructions-light.avif#only-light)
![Edit Project Instructions section showing the Detailed Task Instructions rich-text editor](../../../resources/images/workspaces/user-manual/09-projects/12-edit/02-settings-instructions-dark.avif#only-dark)

#### Imagery

Use the **Imagery** section to review or update the **Imagery JSON Definition**, then select **Save**.

![Edit Project Imagery section showing the Imagery JSON Definition editor and Save button](../../../resources/images/workspaces/user-manual/09-projects/12-edit/03-settings-imagery-light.avif#only-light)
![Edit Project Imagery section showing the Imagery JSON Definition editor and Save button](../../../resources/images/workspaces/user-manual/09-projects/12-edit/03-settings-imagery-dark.avif#only-dark)

#### Team Members

Use the **Team Members** section to search users and review the project role shown for each member. Available roles in the list include **Contributor**, **Lead**, and **Validator**. Remove controls are shown for removable members.

![Edit Project Team Members section showing user search, project roles, and remove controls](../../../resources/images/workspaces/user-manual/09-projects/12-edit/04-settings-team-members-light.avif#only-light)
![Edit Project Team Members section showing user search, project roles, and remove controls](../../../resources/images/workspaces/user-manual/09-projects/12-edit/04-settings-team-members-dark.avif#only-dark)

#### Configuration

The **Configuration** section displays **Lock Timeout** and **Review Required**. If the configuration is locked, Workspaces displays **Settings cannot be changed** and explains that the settings cannot be modified.

![Edit Project Configuration section showing Lock Timeout, Review Required, and a settings-locked message](../../../resources/images/workspaces/user-manual/09-projects/12-edit/05-settings-configuration-light.avif#only-light)
![Edit Project Configuration section showing Lock Timeout, Review Required, and a settings-locked message](../../../resources/images/workspaces/user-manual/09-projects/12-edit/05-settings-configuration-dark.avif#only-dark)

#### Actions

The **Actions** section provides:

- **Reset All Tasks** — removes task assignments and resets task progress to **Not Started** while keeping uploaded imagery, project settings, and team members.
- **Close Project** — changes the project status to **Completed**.
- **Delete Project** — permanently deletes the project and its associated tasks and team members. This action cannot be undone.

Review the explanation shown below each action before selecting a button.

![Edit Project Actions section showing Reset All Tasks, Close Project, Delete Project, and action warnings](../../../resources/images/workspaces/user-manual/09-projects/12-edit/06-settings-actions-light.avif#only-light)
![Edit Project Actions section showing Reset All Tasks, Close Project, Delete Project, and action warnings](../../../resources/images/workspaces/user-manual/09-projects/12-edit/06-settings-actions-dark.avif#only-dark)
