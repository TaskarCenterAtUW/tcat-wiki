## View a Project

This section explains how to find projects in a workspace and review a project’s details, tasks, and contributors.

_For a list of all guides on the TCAT Wiki, refer to the [Guides List](../../../guides-list/index.md)._{ .guides-list-ref }

---

### Open workspace projects

1. **Open** a workspace from the [Dashboard](../dashboard.md)
2. **Select** **Projects** from the workspace actions
3. Review the workspace name and project group shown at the top of the page

The **Projects** page provides the following controls:

- **Search Projects** finds projects by name.
- **Status** filters projects by status.
- **Sort By** changes the order of the project cards.
- **Grid view** and **List view** change the project layout.
- **New Project** starts the project-creation workflow.
- Pagination moves between pages when more projects are available.

Each project card can show its name, status, completion state, completion percentage, creator, and creation date. Select a project card or its **Open project** link to open the project.

### Review a project

Open a project from the Projects page to view its project header, task progress, map, and tabs.

#### Overview

The **Overview** tab can show:

- **Status**
- **Created By**
- **Total Tasks**
- **Created Date**
- **Description**
- The project's task area on the map
- The task status **Legend**

The map legend identifies **Ready for mapping**, **Ready for validation**, **More mapping required**, **Completed**, and **Locked** task states.

![Project Overview tab showing project metadata, description, task area, progress, and task status legend](../../../resources/images/workspaces/user-manual/09-projects/11-view/02-tab-overview-light.avif#only-light)
![Project Overview tab showing project metadata, description, task area, progress, and task status legend](../../../resources/images/workspaces/user-manual/09-projects/11-view/02-tab-overview-dark.avif#only-dark)

#### Instructions

Open the **Instructions** tab to read the project's rich-text task instructions. Instructions can include mapping guidance, tagging requirements, and a table of common issues and fixes.

![Project Instructions tab showing rich-text mapping guidance and a common-issues table](../../../resources/images/workspaces/user-manual/09-projects/11-view/03-tab-instructions-light.avif#only-light)
![Project Instructions tab showing rich-text mapping guidance and a common-issues table](../../../resources/images/workspaces/user-manual/09-projects/11-view/03-tab-instructions-dark.avif#only-dark)

#### Tasks

The **Tasks** tab provides:

- **Search tasks by id**
- **Status** filtering
- **Sort By**
- A task table with **Task ID**, **Status**, **Locked By**, and **Last Updated**
- Pagination

Select a task ID to select that task on the map and open its task action panel.

![Project Tasks tab showing task search, status and sort controls, task table, lock information, and pagination](../../../resources/images/workspaces/user-manual/09-projects/11-view/04-tab-tasks-light.avif#only-light)
![Project Tasks tab showing task search, status and sort controls, task table, lock information, and pagination](../../../resources/images/workspaces/user-manual/09-projects/11-view/04-tab-tasks-dark.avif#only-dark)

#### Contributions

The **Contributions** tab summarizes project activity with cards for:

- **Total Contributors**
- **Leads**
- **Validators**
- **Contributors**

![Project Contributions tab showing Total Contributors, Leads, Validators, and Contributors summary cards](../../../resources/images/workspaces/user-manual/09-projects/11-view/05-tab-contributions-light.avif#only-light)
![Project Contributions tab showing Total Contributors, Leads, Validators, and Contributors summary cards](../../../resources/images/workspaces/user-manual/09-projects/11-view/05-tab-contributions-dark.avif#only-dark)

#### Contributors

The **Contributors** tab manages people and their project roles. Use **Add Contributor**, **Search contributors**, and **All Roles** to find and manage contributors. A contributor row can show a **Contributor**, **Lead**, or **Validator** role and a remove control.

![Project Contributors tab showing Add Contributor, contributor search and role filtering, project roles, and remove controls](../../../resources/images/workspaces/user-manual/09-projects/11-view/06-tab-contributors-light.avif#only-light)
![Project Contributors tab showing Add Contributor, contributor search and role filtering, project roles, and remove controls](../../../resources/images/workspaces/user-manual/09-projects/11-view/06-tab-contributors-dark.avif#only-dark)
