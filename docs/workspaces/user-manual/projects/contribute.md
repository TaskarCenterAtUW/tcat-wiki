## Contribute to a Project

This section explains how to select a project task, make and submit mapping edits, or release a task without submitting it.

_For a list of all guides on the TCAT Wiki, refer to the [Guides List](../../../guides-list/index.md)._{ .guides-list-ref }

---

### Select and map a task

1. Open the project's **Tasks** tab
2. Select a task ID or select a task area on the map
3. Review the selected task and its current status in the bottom action panel
4. **Select** **Map a Task** when you are ready to open the mapping workflow
5. **Select** **Close** to leave the selected-task view without opening the mapping workflow

![Selected project task showing the highlighted task area, Ready for mapping status, Close, and Map a Task](../../../resources/images/workspaces/user-manual/09-projects/13-contribute/01-task-select-light.avif#only-light)
![Selected project task showing the highlighted task area, Ready for mapping status, Close, and Map a Task](../../../resources/images/workspaces/user-manual/09-projects/13-contribute/01-task-select-dark.avif#only-dark)

The selected task remains highlighted on the map, and the task table shows its status. For example, a task can show **Ready for validation** after mapping.

![Project Tasks tab showing a selected task area and Ready for validation status](../../../resources/images/workspaces/user-manual/09-projects/13-contribute/02-task-area-light.avif#only-light)
![Project Tasks tab showing a selected task area and Ready for validation status](../../../resources/images/workspaces/user-manual/09-projects/13-contribute/02-task-area-dark.avif#only-dark)

Selecting **Map a Task** opens the mapping editor. Use the mapping editor to make and save edits, then return to the task panel:

1. Review the task status and remaining lock time
2. Make edits in the mapping editor
3. Push or save your edits before submitting the task
4. Select **I'm Done Mapping** when the task is ready
5. Select **Skip Task** when you need to release the task without submitting it

![Mapping editor for a task showing the task area, Completion tab, mapping status, Skip Task, and I'm Done Mapping](../../../resources/images/workspaces/user-manual/09-projects/13-contribute/03-task-mapped-light.avif#only-light)
![Mapping editor for a task showing the task area, Completion tab, mapping status, Skip Task, and I'm Done Mapping](../../../resources/images/workspaces/user-manual/09-projects/13-contribute/03-task-mapped-dark.avif#only-dark)
