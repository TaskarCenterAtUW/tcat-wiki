## Create a Project

This section explains how to create a project, define its area of interest, configure project settings, and generate project tasks.

_For a list of all guides on the TCAT Wiki, refer to the [Guides List](../../../guides-list/index.md)._{ .guides-list-ref }

---

### Create a project

Use **New Project** to open the four-step project-creation workflow.

#### Step 1: Enter project details

1. **Select** **New Project**
2. Enter a name in **Project Name**
3. Confirm that the name is available
4. Enter a description in **Description**
5. Optionally enter one custom imagery JSON object in **Custom Imagery**
6. **Select** **Next**

![Create New Project details step showing Project Name, name availability, Description, Custom Imagery, and Next](../../../resources/images/workspaces/user-manual/09-projects/10-create/01-new-project-details-light.avif#only-light)
![Create New Project details step showing Project Name, name availability, Description, Custom Imagery, and Next](../../../resources/images/workspaces/user-manual/09-projects/10-create/01-new-project-details-dark.avif#only-dark)

#### Step 2: Define the area of interest

1. Draw the project area on the map with **Draw**
2. Use **Reset** when you need to clear the drawn area
3. Review the **Area of interest captured** summary
4. Use **Download Area of Interest** when you need a copy of the drawn area
5. Alternatively, upload an area-of-interest JSON file in the upload area
6. **Select** **Next**

The area panel displays the captured area and lets you switch between `km²` and `mi²`.

![Create New Project area-of-interest step showing the captured polygon, area summary, download control, and JSON upload area](../../../resources/images/workspaces/user-manual/09-projects/10-create/02-new-area-of-interest-light.avif#only-light)
![Create New Project area-of-interest step showing the captured polygon, area summary, download control, and JSON upload area](../../../resources/images/workspaces/user-manual/09-projects/10-create/02-new-area-of-interest-dark.avif#only-dark)

#### Step 3: Configure project settings

1. Set the **Lock Timeout**
2. Enable or disable **Review Required**
3. Use **Assign Validators** to search for users and assign validator roles
4. Enter project instructions in the rich-text **Instructions** editor
5. **Select** **Next**

The **Lock Timeout** controls when locked tasks are automatically unlocked. **Review Required** requires validator review before tasks can be completed.

![Create New Project settings step showing Lock Timeout, Review Required, validator assignment, and Instructions](../../../resources/images/workspaces/user-manual/09-projects/10-create/03-new-settings-light.avif#only-light)
![Create New Project settings step showing Lock Timeout, Review Required, validator assignment, and Instructions](../../../resources/images/workspaces/user-manual/09-projects/10-create/03-new-settings-dark.avif#only-dark)

#### Step 4: Review and create the project

1. Review the project details, description, imagery URL, area of interest, lock timeout, review requirement, validators, and instructions
2. **Select** **Create Project**

![Create New Project review step showing project details, area of interest, settings, validator, and Create Project](../../../resources/images/workspaces/user-manual/09-projects/10-create/04-new-review-light.avif#only-light)
![Create New Project review step showing project details, area of interest, settings, validator, and Create Project](../../../resources/images/workspaces/user-manual/09-projects/10-create/04-new-review-dark.avif#only-dark)

After the project is created, Workspaces displays a success message. The new project is initially in **Draft** status.

![Project creation success dialog with Go to Projects and Open Tasks Tab actions](../../../resources/images/workspaces/user-manual/09-projects/10-create/05-new-success-light.avif#only-light)
![Project creation success dialog with Go to Projects and Open Tasks Tab actions](../../../resources/images/workspaces/user-manual/09-projects/10-create/05-new-success-dark.avif#only-dark)

#### Generate and save project tasks

1. **Select** **Open Tasks Tab** from the creation success dialog, or open the project's **Tasks** tab
2. Set the task area between `0.25 km²` and `1 km²`
3. **Select** **Generate Tasks**
4. Review the generated task grid on the map

![Project Tasks tab before task generation showing the task-area control, Generate Tasks, Reset, and status legend](../../../resources/images/workspaces/user-manual/09-projects/10-create/06-new-generate-tasks-light.avif#only-light)
![Project Tasks tab before task generation showing the task-area control, Generate Tasks, Reset, and status legend](../../../resources/images/workspaces/user-manual/09-projects/10-create/06-new-generate-tasks-dark.avif#only-dark)

When tasks are generated, the panel reports how many tasks were created and the approximate size of each task.

5. Review the task grid
6. **Select** **Save Tasks**

![Project Tasks tab after task generation showing four created tasks and the Save Tasks control](../../../resources/images/workspaces/user-manual/09-projects/10-create/07-new-save-tasks-light.avif#only-light)
![Project Tasks tab after task generation showing four created tasks and the Save Tasks control](../../../resources/images/workspaces/user-manual/09-projects/10-create/07-new-save-tasks-dark.avif#only-dark)

Workspaces confirms that the tasks are saved and reports how many tasks are available.

![Tasks saved confirmation dialog reporting that four tasks are available and showing Continue](../../../resources/images/workspaces/user-manual/09-projects/10-create/08-new-tasks-saved-light.avif#only-light)
![Tasks saved confirmation dialog reporting that four tasks are available and showing Continue](../../../resources/images/workspaces/user-manual/09-projects/10-create/08-new-tasks-saved-dark.avif#only-dark)

7. **Select** **Continue**
8. Select **Activate Project** when the project is ready to leave **Draft** status

![Project header showing a Draft project with four tasks and the Activate Project button](../../../resources/images/workspaces/user-manual/09-projects/10-create/09-new-activate-project-light.avif#only-light)
![Project header showing a Draft project with four tasks and the Activate Project button](../../../resources/images/workspaces/user-manual/09-projects/10-create/09-new-activate-project-dark.avif#only-dark)
