## Workspaces User Manual

This user manual explains how to use the TDEI Workspaces platform.

_For a list of all guides on the TCAT Wiki, refer to the [Guides List](../../guides-list/index.md)._{ .guides-list-ref }

---

### About Workspaces

[TDEI Workspaces](https://workspaces.sidewalks.washington.edu/) is an integrated editing platform for TDEI datasets. It provides tools and APIs for creating and visualizing OpenSidewalks and GTFS Pathways data.

![TDEI Workspaces landing page with the platform description and Sign In button](../../resources/images/workspaces/user-manual/01-index/01-landing-light.avif#only-light)
![TDEI Workspaces landing page with the platform description and Sign In button](../../resources/images/workspaces/user-manual/01-index/01-landing-dark.avif#only-dark)

---

### Quick Start

1. **Open** [TDEI Workspaces](https://workspaces.sidewalks.washington.edu/)
2. **Sign in** with your TDEI credentials
3. **Select** a project group on the [Dashboard](dashboard.md)
4. **Select** an existing workspace, or [create a workspace](create.md)
5. Use the workspace actions to edit, configure, or [export the workspace](export.md)
