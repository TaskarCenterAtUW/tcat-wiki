## App Settings

This section provides a complete reference for all settings, controls, and features available in AVIV ScoutRoute.

_For a list of all guides on the TCAT Wiki, refer to the [Guides List](../../guides-list/index.md)._{ .guides-list-ref }

---

### My Profile

The **My Profile** page displays your account information and app preferences.

To open it, select your profile button from the map toolbar.

**Available actions:**

- **Enable biometric authentication:** Toggle biometric sign-in. The page warns that disabling it deletes saved credentials for the current environment.
- **Low Bandwidth Mode:** Disable quest images to save data.
- **Show map zoom buttons:** Show or hide the map's **+** and **-** controls.
- **Keep screen on:** Prevent the screen from turning off while the app is open.
- **Delete cache:** Clear cached data if you think some data is outdated.
- **Theme:** View or change the selected theme.
- **Debug:** The section includes **Show Quest Forms**.
- **Logout:** Sign out of your TDEI account.

The three-line menu button opens additional app actions. The profile preferences described above are opened from the profile button, not from a separate Settings menu.

### Download Data

The map includes a download control for the visible area. See [Map Interface](map-interface.md#download-map-data) for details. Downloading data does not guarantee that every app operation will work offline.

### Switch Workspace

**Switch workspace** returns you to the workspace list so you can change workspaces without logging out. The app will ask you to confirm the switch.

**How to access:** Select the workspace name in the top bar of the map view.

![AVIV ScoutRoute confirmation before switching workspaces](../../resources/images/aviv-scoutroute/user-manual/07-app-settings/03-switch-workspace-light.avif#only-light){ .img-contained style="--img-width: 33%;" }
![AVIV ScoutRoute confirmation before switching workspaces](../../resources/images/aviv-scoutroute/user-manual/07-app-settings/03-switch-workspace-dark.avif#only-dark){ .img-contained style="--img-width: 33%;" }

**How to switch:**

1. Select the workspace name in the top bar of the map view, then select **"Switch workspace"**
2. The workspace list appears showing all available workspaces
3. Tap the workspace you want to contribute to
4. The app loads the new workspace

**Use cases:**

- Moving between different project areas
- Working on multiple mapping initiatives

For more details on workspaces, see [Getting Started - Selecting a Workspace](getting-started.md#selecting-a-workspace).

### Display Settings

Configure the visual appearance and behavior of the app.

| Setting                   | Description                                               |
| :------------------------ | :-------------------------------------------------------- |
| **Theme**                 | View or change the selected theme                         |
| **Show map zoom buttons** | Show or hide on-screen **+** and **-** controls           |
| **Keep screen on**        | Prevent the screen from turning off while the app is open |

### Advanced Settings

**Delete cache** is available on the **My Profile** page. Its description recommends using it when some data seems outdated.

See [Undo Changes](map-interface.md#undo-changes) to restore an individually hidden quest.

---

### Debug Settings

The **Debug** section appears on the **My Profile** page.

#### Show Quest Forms

It includes **Show Quest Forms**. Use debug tools only when testing the app or following instructions from the project or support team.
