## TDEI Data Viewer User Manual

This user manual describes the TDEI Data Viewer interface for browsing public project groups, released datasets, mapped features, and issue-reporting controls.

_For a list of all guides on the TCAT Wiki, refer to the [Guides List](../../../guides-list/index.md)._{ .guides-list-ref }

---

### About the TDEI Data Viewer

The [TDEI Data Viewer](https://dataviewer.tdei.us/) presents public TDEI project groups and their released datasets. Project group pages combine dataset search with a map, while each dataset has a map view with boundary controls, a feature-type legend, and feature details.
