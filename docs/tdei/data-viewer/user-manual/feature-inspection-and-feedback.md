## Feature Inspection and Feedback

This section describes the Inspect panel and the information shown in the issue-reporting form.

_For a list of all guides on the TCAT Wiki, refer to the [Guides List](../../../guides-list/index.md)._{ .guides-list-ref }

---

### Inspect a Map Feature

Right-clicking a feature opens the **Inspect** panel. The map instructions identify right-click as the pointer interaction and state that all actions are available by keyboard. The panel displays the latitude and longitude of the selected map location, the OpenStreetMap (OSM) element type and ID, and a **Report Issue** control.

![TDEI Data Viewer Inspect panel showing selected-location coordinates and the OpenStreetMap element type and ID](../../../resources/images/tdei/data-viewer/user-manual/04-feature-inspection-and-feedback/inspect-panel-light.avif#only-light)
![TDEI Data Viewer Inspect panel showing selected-location coordinates and the OpenStreetMap element type and ID](../../../resources/images/tdei/data-viewer/user-manual/04-feature-inspection-and-feedback/inspect-panel-dark.avif#only-dark)

### Report Issue Form

Selecting **Report Issue** opens a form associated with the dataset and inspected location. **Email Address** and **Your Feedback** are required fields. The form indicates that a submitted report includes the current GPS location, dataset and element information, OSM reference, and submission timestamp.

**Cancel** closes the form without submitting. **Submit Feedback** is the report submission control.

![TDEI Data Viewer Report Issue form showing dataset context and the required fields](../../../resources/images/tdei/data-viewer/user-manual/04-feature-inspection-and-feedback/report-issue-form-light.avif#only-light)
