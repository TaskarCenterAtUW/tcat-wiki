# What is the Rapid editor?

## Short Answer

Rapid is an OpenStreetMap editing tool designed to help users add or improve map features with a focused editing workflow. Current features, presets, imagery, and integrations depend on the Rapid version and configuration.

## Significance

Rapid can make certain mapping tasks more approachable and can support structured editing when users follow the relevant project and OpenStreetMap practices.

## What This Means

Review the current editor guidance, select the correct area and imagery, make evidence-based edits, validate them, and follow the applicable community or project review process.

## What This Does Not Mean

Rapid is not an authoritative survey, accessibility certification, or guarantee that an edit is correct. Its existence does not imply a current OS-CONNECT or Workspaces integration.

## How To Use This

Use Rapid for supported OpenStreetMap editing tasks, document the source and reasoning for accessibility-related edits, and verify current integrations before promising a specific workflow.

## Example

A mapper uses Rapid to add a missing sidewalk from current imagery, checks connectivity and tags, and submits the edit according to OpenStreetMap practice.

## Assistant Guidance

Distinguish Rapid from OS-CONNECT, Workspaces, and other products. Cite current Rapid documentation, avoid inventing presets or integrations, and abstain when version-specific behavior is unknown.
