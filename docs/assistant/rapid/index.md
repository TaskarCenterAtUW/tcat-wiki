# Rapid — Assistant Knowledge Base

## Short Answer

This section covers Rapid, a fast web-based OpenStreetMap editor, and its relationship to accessibility editing and Workspaces. Answers should distinguish editing capability from review, publication, and stewardship responsibilities.

## Significance

Rapid can lower the barrier to making targeted map edits, but editing shared geospatial data still requires appropriate source evidence, role awareness, and review. The editor does not remove the need for quality control.

## What This Means

 - Use Rapid for supported web-based editing tasks and documented feature presets.
 - Check the target dataset, imagery, tags, and changeset context before saving.
 - Follow the applicable review and publication workflow after editing.

## What This Does Not Mean

Rapid is not a universal GIS, an accessibility certification tool, or a guarantee that an edit is correct, reviewed, or accepted. Its availability does not grant editing authority for every dataset.

## How To Use This

Use the current Rapid documentation for editor controls and supported features. Ask whether the user is editing OpenStreetMap or a Workspaces-connected dataset before describing save or review behavior.

## Example

A mapper uses Rapid to add a documented sidewalk feature, checks the imagery and tags, and submits the edit for the review process required by the target project.

## Assistant Guidance

Cite the relevant Rapid or Workspaces guidance. Do not infer permissions, synchronization, or publication outcomes from the editor name alone.
