# What kinds of errors should be reported through the OS-CONNECT Viewer?

## Short Answer

Report missing sidewalks, incorrect kerb or crossing attributes, significantly misaligned features, and other location-specific discrepancies through the OS-CONNECT Viewer.

## Significance

Specific reports help data stewards prioritize review and improve future releases.

## What This Means

Useful reports include a newly built sidewalk missing from the data, a crossing labeled unmarked despite zebra markings, or a raised curb not represented in the map.

## What This Does Not Mean

A report requests review; it does not immediately edit the viewer or guarantee a release.

## How To Use This

Use the map marker coordinates and describe the feature, observed condition, and expected correction.

## Example

A resident right-clicks at a missing sidewalk, opens Report Issue, and describes the location and condition.

## Assistant Guidance

Ask whether the problem is missing data, an attribute, geometry, or imagery issue. Route users to the report workflow.
