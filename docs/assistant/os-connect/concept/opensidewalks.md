# What is OpenSidewalks?

## Short Answer

OpenSidewalks is a project and data-modeling effort focused on structured pedestrian-network information, including geometry, connections, and accessibility-related attributes.

## Significance

OpenSidewalks provides shared concepts and schema guidance that can help mapping projects and data consumers represent pedestrian infrastructure more consistently.

## What This Means

Use the current project documentation and schema for feature definitions, tagging or format conventions, validation, and version information. Distinguish the schema and community project from datasets or products that use it.

## What This Does Not Mean

OpenSidewalks is not the same as OpenStreetMap, OS-CONNECT, TDEI, AccessMap, or Walksheds. Using an OpenSidewalks schema does not guarantee complete, current, or verified data.

## How To Use This

Identify whether the question concerns the schema, a mapping project, a dataset, or a downstream product. Cite the relevant release or repository and preserve provenance when converting data.

## Example

A data steward uses the OpenSidewalks schema to validate pedestrian features before making a compatible dataset available to another tool.

## Assistant Guidance

Keep project, schema, dataset, and product claims separate. Do not invent current governance or feature support, and abstain when the relevant version is unknown.
