# Why was OS-CONNECT created?

## Short Answer

OS-CONNECT was created to address fragmented, inconsistent, and difficult-to-use pedestrian-network information by supporting a connected, structured, and more interoperable view of pedestrian infrastructure.

## Significance

Shared pedestrian data can support accessibility-aware analysis, planning, stewardship, and public understanding across jurisdictions and tools.

## What This Means

The project provides a common data and network context that can be used with local knowledge, validation, planning workflows, and related accessibility tools. Its purpose and scope should be read from the current project documentation.

## What This Does Not Mean

Creation of OS-CONNECT does not mean that all pedestrian data are complete, that all jurisdictions share one authority, or that the dataset replaces local inventories, field work, or legal review.

## How To Use This

Use the origin statement to understand purpose, then check the exact release, scope, methods, and limitations for a current question.

## Example

An agency uses OS-CONNECT to connect previously separate pedestrian datasets and identify areas for local validation and planning discussion.
