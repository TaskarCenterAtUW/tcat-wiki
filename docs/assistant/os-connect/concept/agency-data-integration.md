# Can agencies provide their own sidewalk or curb-ramp data for integration?

## Short Answer

Agencies can offer sidewalk, curb-ramp, or related pedestrian data for consideration in an OS-CONNECT workflow. The data must be reviewed for scope, provenance, format, quality, and compatibility before it is treated as part of a released dataset.

## Significance

Agency data can add local detail or help identify gaps in a broader inventory. A documented integration process protects data lineage and prevents an unreviewed source from being treated as authoritative automatically.

## What This Means

- Describe the source, geographic coverage, date, licensing, schema, and intended use.
- Ask the current OS-CONNECT or TDEI steward how to submit the data.
- Expect review, validation, reconciliation, and release decisions before public use.

## What This Does Not Mean

Providing a file does not guarantee that it will be accepted, merged, published, or displayed immediately. An agency submission does not automatically replace other sources or update OpenStreetMap.

## How To Use This

Prepare documentation and a small representative sample when requesting integration. Separate authoritative agency records from reference or field-observation layers, and retain the source version and contact for follow-up.

## Example

An agency supplies a curb-ramp inventory with coverage and collection dates. The steward compares it with existing pedestrian data, resolves differences through review, and documents the source before any release decision.

## Assistant Guidance

Do not promise a specific upload route, schema acceptance, merge result, or release date. Ask for source and scope details, cite current submission guidance, and abstain when the integration workflow is not confirmed.
