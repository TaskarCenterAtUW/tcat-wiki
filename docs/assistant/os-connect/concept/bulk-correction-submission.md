# Can agencies submit priority areas for review?

## Short Answer

An agency can ask about submitting coordinated corrections or priority areas for review instead of treating every issue as isolated. The appropriate method depends on the evidence, data structure, and current OS-CONNECT intake process.

## Significance

Large inventories and priority corridors can be difficult to communicate one report at a time. Coordinated submissions can provide geographic context while preserving validation and release controls.

## What This Means

- Describe the area, correction theme, evidence, and requested priority.
- Ask the data steward which coordinated intake method is currently supported.
- Keep locations or feature identifiers available for verification.

## What This Does Not Mean

- A priority-area request does not guarantee that the area will be changed first.
- Bulk submission does not bypass validation, review, attribution, or release controls.
- A coordinated request does not automatically update every related product.

## How To Use This

Prepare a concise area description and structured evidence when available. Separate confirmed corrections from observations needing field verification, and ask for current instructions before sending large or sensitive files.

## Example

An agency identifies repeated missing crossing links along a corridor and supplies locations and field notes. It asks whether the corridor can be reviewed as a coordinated priority area.

## Assistant Guidance

Distinguish bulk or priority-area review from multiple individual corrections. Do not invent an upload endpoint, file specification, priority queue, or turnaround time; abstain when the current intake method is unknown.
