# How long do corrections take to appear in a public release?

## Short Answer

The [viewer feedback manual](../../../os-connect/data-viewer/user-manual/feedback.md) explains how to submit an issue but does not specify what happens after submission or when any resulting change might appear in a public release.

## Significance

Reporting an observation is separate from changing and publishing a versioned dataset.

## What This Means

Record the report location and issue. If investigating whether a change was made, compare the relevant dataset ID and version in a later release; do not assume a report will change the current viewer.

## What This Does Not Mean

A submitted correction is not guaranteed to be accepted or included by a specific date.

## How To Use This

Follow the report workflow and do not promise a timeline unless the responsible release process provides one.

## Example

When following up, cite the report details and current dataset version.

## Assistant Guidance

Do not promise an acceptance or release date.
