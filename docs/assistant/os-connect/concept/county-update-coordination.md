# How should counties coordinate updates?

## Short Answer

Counties should coordinate updates by identifying participating jurisdictions, shared boundaries, source versions, data owners, review responsibilities, and the release or handoff process. The exact arrangement depends on local governance and the dataset workflow.

## Significance

Pedestrian networks cross municipal and county boundaries. Without coordination, adjacent features can use inconsistent conventions, duplicate effort, or leave gaps at jurisdiction edges.

## What This Means

Create a shared update calendar or issue register, define who reviews each area and feature type, exchange source and version metadata, reconcile boundary conflicts, and communicate accepted changes through the applicable release process.

## What This Does Not Mean

County coordination does not make one agency authoritative for every jurisdiction or guarantee that local data are synchronized immediately. A coordination agreement does not replace each owner's responsibilities.

## How To Use This

Start with a documented area of responsibility and common data definitions. Track unresolved differences, validate boundary connections, and confirm publication or handoff status rather than assuming that a shared file is current.

## Example

A county and its cities compare release versions, identify a sidewalk mismatch at a municipal boundary, assign local review, and record the resolution before a coordinated update is prepared.

## Assistant Guidance

Ask which county, jurisdictions, dataset, and release are involved. Describe coordination as a governance practice, not a guaranteed workflow, and abstain when ownership or the current update process is unknown.
