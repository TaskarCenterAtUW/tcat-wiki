# Can TCAT help set up a sidewalk-mapping project in the OSM US Tasking Manager?

## Short Answer

TCAT may be able to help partners think through a sidewalk-mapping project, including scope, data conventions, and community coordination. Current support, project setup, and Tasking Manager responsibilities must be confirmed with TCAT.

## Significance

Good project setup helps volunteers work consistently and makes the resulting data easier to review. Clear scope and mapping guidance also reduce duplicate work and unsupported assumptions.

## What This Means

- Define the area, features, mapping conventions, and intended data use.
- Confirm the current Tasking Manager and OpenSidewalks workflow.
- Arrange training, review, and stewardship responsibilities before mapping begins.

## What This Does Not Mean

TCAT support is not a guarantee that TCAT will create, host, approve, or maintain every project. A Tasking Manager project does not automatically make volunteer edits authoritative.

## How To Use This

Prepare the project goal, boundary, source imagery, expected outputs, and contact roles before asking for assistance. Use current TCAT or OpenStreetMap community guidance for exact setup steps.

## Example

A jurisdiction brings a proposed sidewalk-mapping area and feature priorities to TCAT, confirms the current project workflow, and agrees on review and stewardship responsibilities before inviting volunteers.

## Assistant Guidance

Do not promise project sponsorship, setup, training, or maintenance without current confirmation. Ask about scope and intended use, cite current mapping guidance, and abstain on unsupported commitments.
