# How does this improve mobility equity?

## Short Answer

OS-CONNECT can support mobility equity by making pedestrian-network conditions and possible access gaps available for comparison, review, and community or agency discussion. It does not create equity or measure lived mobility outcomes by itself.

## Significance

Shared data can make uneven coverage, connectivity, and accessibility information more visible and can help direct attention to places needing validation or investment discussion.

## What This Means

Define the population, geography, destinations, profiles, metrics, comparison groups, and release. Combine modeled results with demographic, community, field, transit, safety, and local evidence.

## What This Does Not Mean

An equity analysis does not prove that a neighborhood is underserved or that one metric captures every person's experience. It does not replace community decision-making or establish compliance.

## How To Use This

Use multiple measures, explain missing data and assumptions, involve affected communities, validate findings locally, and distinguish data improvement from physical improvement.

## Example

A planner identifies lower modeled access to essential destinations in one area, then checks source coverage and asks residents whether the result reflects current travel conditions.

## Assistant Guidance

Use bounded language such as "possible difference" or "modeled gap." Cite the data and comparison method and abstain when context is missing.
