# What future capabilities are planned for OS-CONNECT?

## Short Answer

Future OS-CONNECT capabilities should be described only from a current, verified roadmap, project announcement, or release plan. Do not treat possible improvements, integrations, coverage, or analysis features as current until documented.

## Significance

Separating possibilities from released functionality prevents agencies and communities from planning around an unconfirmed feature or timeline.

## What This Means

When a roadmap is available, record its source and date and distinguish proposed, experimental, planned, and released work. Use current product documentation for present capabilities.

## What This Does Not Mean

Mentioning a future possibility is not a commitment, schedule, funding decision, or guarantee of delivery.

## How To Use This

Answer current-use questions from current documentation. Label future-facing information clearly, avoid unsupported feature lists, and direct clarification through the verified support or Office Hours path when appropriate.

## Example

A partner asks whether a new statewide update or automated review capability is planned. Staff state that only a verified roadmap can confirm it and describe the current release separately.

## Assistant Guidance

Do not invent planned capabilities or dates. Cite current roadmap evidence or state that no verified information is available, and abstain when internal confirmation is required.
