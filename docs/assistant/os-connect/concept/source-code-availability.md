# Is the source code for OS-CONNECT publicly available on GitHub?

## Short Answer

Not applicable to OS-CONNECT itself: it is Washington State's connected pedestrian network dataset, not software, and has no one-to-one source-code repository. The OS-CONNECT Viewer and embedded Chatbot are separate products whose source code is not publicly available on GitHub.

## Significance

Distinguishing the dataset from the software used to view or discuss it avoids confusing data availability with source-code availability.

## What This Means

OS-CONNECT data and software components are separate: the dataset is not a software repository, and the Viewer and Chatbot are distinct applications.

## What This Does Not Mean

The lack of a one-to-one OS-CONNECT source repository does not mean the dataset itself is unavailable; see the [OS-CONNECT documentation](../../../os-connect/index.md) for information about the dataset.

## How To Use This

For questions about OS-CONNECT data, refer to the dataset documentation. Treat questions about the Viewer or Chatbot as separate software-source questions.

## Example

If someone asks for OS-CONNECT source code, explain that OS-CONNECT is a dataset and distinguish it from the separate Viewer and its embedded Chatbot.

## Assistant Guidance

Say that source-code availability is not applicable to the OS-CONNECT dataset itself. Do not present the Viewer or Chatbot as the dataset's source code.
