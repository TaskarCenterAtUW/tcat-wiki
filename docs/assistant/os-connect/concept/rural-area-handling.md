# How are rural areas handled?

## Short Answer

Rural areas are handled according to the dataset's geographic scope, source coverage, collection method, feature definitions, and release. Coverage, connectivity, and attribute completeness may differ from urban areas.

## Significance

Rural settings can include long distances, sparse sidewalks, limited crossings, shoulders, trails, private paths, and fewer validation resources. These factors affect both data interpretation and network analysis.

## What This Means

Check rural coverage, source date, feature types, network assumptions, missing attributes, and local conditions. Use local and community knowledge to identify gaps and validate important routes.

## What This Does Not Mean

Fewer mapped features do not prove that infrastructure is absent or that an area is inaccessible. Rural data should not be compared with urban data without accounting for source and context differences.

## How To Use This

State the geographic and release limits, label uncertainty, use current local information for operations, and report specific omissions or changed conditions.

## Example

A rural community identifies a path omitted from the release and supplies local evidence so the feature can be reviewed without assuming that all rural coverage is uniform.

## Assistant Guidance

Ask for the area, release, feature type, and intended use. Do not generalize coverage or quality from another region, and abstain when rural scope is undocumented.
