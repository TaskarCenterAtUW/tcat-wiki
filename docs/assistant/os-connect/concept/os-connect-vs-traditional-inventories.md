# What makes OS-CONNECT different from traditional inventories?

## Short Answer

OS-CONNECT differs from a traditional inventory in its connected pedestrian-network representation, shared schema and release context, broader cross-jurisdiction use, and potential support for network analysis. The exact distinction depends on the inventory being compared.

## Significance

Network structure and interoperable fields can support questions that a list of assets or isolated local records cannot answer easily.

## What This Means

Compare scope, geometry, connectivity, attributes, source, authority, collection date, maintenance, licensing, and intended use. Treat each inventory as a distinct source until lineage and reconciliation are documented.

## What This Does Not Mean

OS-CONNECT is not automatically more accurate, more current, or more authoritative than a local inventory. A connected representation does not replace local asset-management or inspection records.

## How To Use This

Use OS-CONNECT for appropriate network and comparative analysis, local inventories for current local operations where authoritative, and validate differences before making decisions.

## Example

An agency uses OS-CONNECT to screen regional connectivity and its own inventory to manage inspected curb ramps, documenting why the sources differ and which one supports each decision.

## Assistant Guidance

Avoid broad superiority claims. Name the compared inventories, versions, and measures, cite evidence, and abstain when scope or authority is unknown.
