# What kinds of pedestrian infrastructure are not included?

## Short Answer

Infrastructure may be excluded when it is outside the dataset's geographic scope, source coverage, feature definitions, access permissions, collection method, or release. The exact exclusions must be checked in the release documentation.

## Significance

Knowing exclusions prevents users from interpreting an absent feature as proof that the infrastructure does not exist.

## What This Means

Check feature definitions, private or restricted access, campus and trail coverage, rural or complex locations, collection dates, and source limitations. Record which categories were outside the analysis.

## What This Does Not Mean

An excluded feature is not necessarily inaccessible, and an included feature is not automatically current, public, or usable. Exclusions do not establish ownership or compliance.

## How To Use This

Read the metadata for the exact release, state exclusions next to maps or metrics, supplement with authoritative local data when needed, and validate important locations.

## Example

A planner finds no mapped path inside a restricted campus area. The planner checks the dataset scope and campus records before describing it as a data-coverage limitation.

## Assistant Guidance

Do not provide a universal exclusion list without release evidence. Cite the source scope, distinguish absence from exclusion, and abstain when coverage definitions are unknown.
