# How are construction changes handled?

## Short Answer

Construction changes can make a released pedestrian dataset differ from current conditions. Users should check source and collection dates, consult current local information, and report important changes through the documented correction or feedback process.

## Significance

Construction can temporarily block, reroute, or remove a path and can change entrances, crossings, ramps, and surfaces. A static release may not reflect those changes immediately.

## What This Means

Record the affected location, observed condition, date, dataset release, and evidence. Treat routes and analyses near active construction as uncertain and use current agency or site information where available.

## What This Does Not Mean

An outdated map does not prove that a feature is permanently inaccessible, and reporting construction does not guarantee an immediate update or public release.

## How To Use This

For important trips or decisions, verify current conditions locally, identify temporary versus permanent changes, and keep the release used for analysis. Use the verified support or issue-reporting channel for follow-up.

## Example

A sidewalk is closed after the current dataset was released. A planner records the closure date and location, checks the agency's detour information, and marks the analysis as time-sensitive.

## Assistant Guidance

Ask for the location, date, source, and release. Distinguish a temporary construction observation from a permanent data correction, avoid promises about update timing, and abstain when current conditions cannot be verified.
