# How often is the dataset updated?

## Short Answer

The OS-CONNECT update cadence is release- and workflow-dependent. Check the current dataset metadata, release notes, or published maintenance information for the exact area and version rather than assuming a universal schedule.

## Significance

Update timing affects whether a release reflects current construction, maintenance, development, attributes, and corrections.

## What This Means

Record the release date, source and collection dates, correction status, and known lag. Use current local records for time-sensitive operational decisions.

## What This Does Not Mean

A published cadence does not guarantee that every change appears in the next release or that the data are current at every location.

## How To Use This

Check the exact release before analysis, report important changes through the current channel, and revisit results when a relevant release changes.

## Example

An agency reports a missing crossing and records the release examined, then checks later release information rather than assuming an immediate update.

## Assistant Guidance

Do not invent a schedule or promise a correction date. Cite current release information and abstain when cadence or status is not documented.
