# How could national accessibility data standards evolve?

## Short Answer

National accessibility data standards could evolve through clearer definitions, interoperable schemas, stronger provenance and versioning, better representation of uncertainty and lived experience, common validation practices, and support for changing and temporary conditions.

## Significance

Shared standards can reduce translation costs and make data more useful across jurisdictions, tools, and modes while preserving local context.

## What This Means

Standards work should involve people with disabilities, communities, jurisdictions, transit agencies, researchers, vendors, and data stewards. It should define semantics, identifiers, licensing, privacy, quality, accessibility, and governance.

## What This Does Not Mean

There is no single agreed future standard implied by this article, and a common schema does not make data complete, authoritative, or interchangeable automatically.

## How To Use This

Compare proposed standards with current use cases, test them across places and feature types, publish versioned changes, and document migration and stewardship responsibilities.

## Example

A standards group adds explicit uncertainty and source-date fields to a pedestrian schema and tests whether agencies and consumers can preserve those meanings through conversion.

## Assistant Guidance

Present these as possibilities, not commitments. Cite current standards work when available and abstain from claiming a roadmap or consensus without evidence.
