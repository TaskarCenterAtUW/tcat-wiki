# How should planners validate the data?

## Short Answer

Planners should validate OS-CONNECT data against the exact release, source metadata, local authoritative records, imagery, field observations, and community knowledge that fit the intended decision.

## Significance

Validation helps planners understand whether geometry, connectivity, attributes, and currency are adequate for a particular analysis.

## What This Means

Define the decision and acceptable uncertainty, inspect coverage and provenance, sample ordinary and complex locations, compare relevant attributes, document discrepancies, and preserve versions and evidence.

## What This Does Not Mean

Validation does not prove that every feature is accurate, accessible, current, or legally sufficient. A quality metric is not a substitute for local judgment.

## How To Use This

Use risk-based review, validate high-consequence findings locally, state known errors beside conclusions, and report supported corrections through the current channel.

## Example

A planner checks a sample of crossings near a proposed project against current agency records and field observations before using the network results in a prioritization study.

## Assistant Guidance

Ask for the geography, release, purpose, comparison sources, and decision stakes. Cite the validation method and avoid claims beyond the sample.
