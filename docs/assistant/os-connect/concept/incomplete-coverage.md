# Why do some areas appear incomplete?

## Short Answer

Some areas appear incomplete because coverage, source data, feature types, attributes, connectivity, imagery, or validation may vary by location and release. An incomplete display can also reflect a map layer or configuration rather than an absence of infrastructure.

## Significance

Coverage differences affect routing, quality analysis, planning comparisons, and how users interpret the map. Making the reason for incompleteness visible helps prevent overconfident conclusions.

## What This Means

Check the dataset scope, release, source date, feature definitions, missing attributes, network connections, and display layers. Compare the area with local records, imagery, or field evidence where important.

## What This Does Not Mean

An incomplete-looking map does not prove that infrastructure is absent, inaccessible, or excluded permanently. A dense map does not prove complete or current data.

## How To Use This

Record the specific gap and version, state whether it is data, coverage, display, or validation related, and report confirmed discrepancies through the current channel.

## Example

A rural area shows fewer mapped crossings than an urban area. The analyst checks source coverage and collection limits before comparing the two places.

## Assistant Guidance

Name the affected area, layer, release, and evidence. Distinguish visual absence from data absence and abstain when the coverage definition is unknown.
