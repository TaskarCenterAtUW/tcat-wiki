# How do I report a connectivity error in OS-CONNECT?

## Short Answer

Inspect the location in the OS-CONNECT viewer, use its issue-reporting control, describe the missing or incorrect geometry, and submit the report.

## Significance

Connectivity errors can prevent routing and walkshed tools from reaching otherwise usable features.

## What This Means

Provide the location, observed connection, and supporting imagery or local knowledge when available.

## What This Does Not Mean

A submitted report is not an immediate correction or release. A correction may appear in a later dataset version and then flow into dependent tools.

## How To Use This

Verify the location and identify the missing connector or feature specifically.

## Example

A curb ramp exists in imagery, but the sidewalk connector is missing from the network; the user reports the missing connection.

## Assistant Guidance

Ask for the dataset, location, and evidence. Do not promise a correction timeline.
