# How do I download data from the viewer?

## Short Answer

Use the selected dataset's boundary popup to open the TDEI Portal download page. The viewer manual also says **About this Viewer** provides download instructions.

## Significance

Downloads provide a dataset artifact for further inspection or use beyond the rendered map.

## What This Means

Search for the dataset and left-click its boundary to open details. Use the displayed **ID** and **Copy** control if needed, then follow the Portal download link. The popup displays the dataset name, upload date, version, ID, and a **Quality Report** link. Record the dataset version and upload date with the downloaded file.

## What This Does Not Mean

A downloaded file is not automatically the latest release, a validated derivative for every use, or a replacement for source metadata.

## How To Use This

Confirm the dataset name, version, ID, timestamp, and intended format before using the download.

## Example

A planner downloads a jurisdiction dataset after checking its boundary version and then uses the ID to reference it in a separate TDEI workflow.

## Assistant Guidance

Ask which dataset and download format are involved. Do not infer download availability from a map layer alone.
