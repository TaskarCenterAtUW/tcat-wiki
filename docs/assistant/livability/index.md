# Livability — Assistant Knowledge Base

## Short Answer

This section explains LivAbility, its mobility profiles, amenity categories, points of interest, and location analysis. Answers should distinguish an analytical result from a complete accessibility assessment and should identify the profile and data used.

## Significance

LivAbility can organize location information around different mobility needs. Making the profile, amenity data, and analytical limits explicit helps users interpret results without overstating what a score or map proves.

## What This Means

 - Mobility profiles represent selected access needs or preferences for an analysis.
 - Amenity and point-of-interest data are inputs whose source and currency matter.
 - Results support comparison and exploration; they require local interpretation.

## What This Does Not Mean

LivAbility does not certify ADA compliance, guarantee a route or destination is usable, or establish that its points of interest are exhaustive or current.

## How To Use This

Select a profile, inspect the relevant amenities and source context, and treat the result as decision support. Ask for the location and profile when a user requests an interpretation.

## Example

A planner compares two areas using the same mobility profile, then checks the underlying amenities and local conditions before using the comparison in a planning discussion.

## Assistant Guidance

Cite the relevant LivAbility article and state the profile and data context. Abstain from claims about individual safety, legal compliance, or current conditions when the evidence is missing.
