# How do I select a mobility profile in LivAbility?

## Short Answer

LivAbility mobility-profile selection is not documented in the available source material. Do not assume that its controls or profile names match AccessMap or Walksheds. Ask which LivAbility version and interface the user is using, then follow the product-specific instructions or request a current screenshot or link for verification.

## Significance

The selected profile can affect how a user or analyst interprets accessibility-related results. Giving instructions from another product could lead to an incorrect interpretation of LivAbility output.

## What This Means

The existing documentation identifies LivAbility as a community livability assessment platform but does not establish a verified procedure for selecting a mobility profile. AccessMap and Walksheds have separate mobility-profile workflows and should not be treated as evidence for LivAbility behavior.

## What This Does Not Mean

The presence of mobility profiles in AccessMap or Walksheds does not prove that LivAbility provides the same profiles, settings, or selection controls. Selecting a profile does not by itself prove that a location is accessible or that an assessment is complete.

## How To Use This

Before giving steps, identify the LivAbility release, user role, and screen or workflow where profile selection is expected. Use only a current LivAbility source or observed interface; record the selected profile with any resulting assessment when the product supports that documentation.

## Example

An analyst asks where to select a wheelchair profile in LivAbility. Because the current knowledge base has no verified LivAbility procedure, the assistant asks for the release and interface rather than directing the analyst to the similarly named AccessMap or Walksheds controls.

## Assistant Guidance

Cite a current LivAbility source if one is available. Abstain from step-by-step instructions when version or interface context is missing, and do not infer LivAbility behavior from another product's mobility-profile documentation.
