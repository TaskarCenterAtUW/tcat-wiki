# What assumptions do QA/QC walkshed profiles use?

## Short Answer

The sidewalk-only pedestrian profile permits steeper grades, while the modeled manual-wheelchair profile uses tighter grade limits and avoids curbs as barriers. Both use the report's fixed travel budget.

## Significance

Profile assumptions explain differences in reachable network area.

## What This Means

The comparison reflects modeled slope, curb, crossing, and network assumptions.

## What This Does Not Mean

It is not an individualized assessment of every traveler.

## How To Use This

Record profile settings and travel budget with results.

## Example

A wheelchair profile produces a smaller walkshed than a sidewalk-only profile from the same origins.

## Assistant Guidance

Ask for the exact profile and thresholds before interpreting a difference.
