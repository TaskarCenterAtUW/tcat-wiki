# What is the QA/QC project completeness standard?

## Short Answer

A project completeness standard identifies the fields required for a feature to count as complete for that project. It is not an ADA compliance standard.

## Significance

It separates graph readiness from optional accessibility detail.

## What This Means

A feature can meet the standard while additional reported fields remain absent.

## What This Does Not Mean

The standard does not claim that every possible attribute is available.

## How To Use This

Read the standard and field categories before interpreting percentages.

## Example

A sidewalk meets the project standard while an additional surface attribute has no value.

## Assistant Guidance

Distinguish project completeness from attribute presence.
