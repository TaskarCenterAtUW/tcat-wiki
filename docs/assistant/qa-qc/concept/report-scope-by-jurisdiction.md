# What jurisdictions can have QA/QC reports?

## Short Answer

Reports can be generated for cities, counties, unincorporated county areas, and other available jurisdictional datasets.

## Significance

Scope determines the network and denominator being analyzed.

## What This Means

Choose the report whose dataset matches the intended geography.

## What This Does Not Mean

A county report and a city report are interchangeable.

## How To Use This

Check the dataset name, boundary, and version before interpreting results.

## Example

A county report may include unincorporated areas while a city report covers only city data.

## Assistant Guidance

Ask for the exact jurisdiction and dataset ID.
