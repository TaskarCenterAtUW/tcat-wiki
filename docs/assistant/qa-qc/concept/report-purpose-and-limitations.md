# What is the purpose of a QA/QC report?

## Short Answer

A QA/QC report summarizes mapped pedestrian-network contents, attribute completeness, connectivity, and potential priority locations for a dataset.

## Significance

It helps non-technical readers understand what the mapped dataset can support and where follow-up may be useful.

## What This Means

Use the report as decision support about mapped data, not as a substitute for field verification, professional accessibility review, or regulatory analysis.

## What This Does Not Mean

Report results do not prove that every mapped feature matches current real-world conditions or establishes compliance.

## How To Use This

Check the dataset version, imagery or collection context, metrics, assumptions, and limitations before acting on a result.

## Example

A hotspot can identify a location for an on-the-ground check before a project is prioritized.

## Assistant Guidance

Ask which dataset and report version are being interpreted. Do not overstate report certainty.
