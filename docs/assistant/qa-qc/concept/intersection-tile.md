# What does an intersection tile mean?

## Short Answer

An intersection tile is a small analysis area centered on an intersection or network node.

## Significance

It gives report metrics a consistent geographic unit for mapping and comparison.

## What This Means

The tile summarizes intersection-related values for the network features represented there.

## What This Does Not Mean

A tile is not a parcel, service area, or exact field-survey boundary.

## How To Use This

Read the metric definition and map legend before comparing tiles.

## Example

A map may color each tile by traversability or centrality.

## Assistant Guidance

Explain that tile values are analysis summaries, not direct observations.
