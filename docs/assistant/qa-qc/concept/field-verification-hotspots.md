# How are QA/QC field-verification hotspots used?

## Short Answer

Hotspots identify locations where mapped data or network structure merits on-the-ground checking.

## Significance

They help focus limited field-validation effort.

## What This Means

Use the report to choose locations, then verify conditions directly.

## What This Does Not Mean

A hotspot is not proof that a feature is defective or missing.

## How To Use This

Record the field result and update the source workflow when appropriate.

## Example

A disconnected crossing hotspot is visited to confirm whether the mapped gap exists.

## Assistant Guidance

Separate modeled evidence from field observations.
