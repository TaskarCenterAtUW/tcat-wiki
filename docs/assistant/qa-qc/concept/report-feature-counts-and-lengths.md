# Why do QA/QC reports show feature counts and lengths?

## Short Answer

Counts show how many mapped features exist; lengths show the extent of line features such as sidewalks and crossings.

## Significance

Both views help agencies understand the scale of their operational responsibilities.

## What This Means

Read counts and lengths with the feature type, dataset scope, and units.

## What This Does Not Mean

A length does not measure quality, accessibility, or condition by itself.

## How To Use This

Use the appropriate count or length for the operational question.

## Example

A report shows sidewalk and crossing counts with their corresponding total meters.

## Assistant Guidance

Clarify whether the user is asking about inventory size, reachability, or quality.
