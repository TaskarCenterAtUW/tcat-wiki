# What is the QA/QC report glossary for?

## Short Answer

The glossary defines technical terms as they are used in a QA/QC report, helping readers interpret its profiles, data categories, maps, and metrics.

## Significance

Clear definitions reduce misinterpretation of metrics and data fields.

## What This Means

The report glossary appears near the beginning, before provenance and analysis sections, and defines terms such as accessibility island, attribute completeness, barrier, betweenness centrality, tile aggregation, and normalized values.

## What This Does Not Mean

A definition alone does not explain every calculation or limitation.

## How To Use This

Look up unfamiliar terms in the report's own glossary before interpreting a score, then consult the relevant metric article or method for calculation details.

## Example

A reader finds “log-normalized” in the report glossary, then checks the centrality section to learn which values use that display scale rather than treating it as a percentage.

## Assistant Guidance

Prefer the glossary included in the specific report over an inferred or remembered definition. If it does not define a term or its calculation, say so and consult the report's method rather than inventing a meaning.
