# What is the QA/QC report glossary for?

## Short Answer

The glossary defines technical terms used in QA/QC reports for non-technical readers.

## Significance

Clear definitions reduce misinterpretation of metrics and data fields.

## What This Means

Use the glossary alongside the relevant section and method.

## What This Does Not Mean

A definition alone does not explain every calculation or limitation.

## How To Use This

Look up unfamiliar terms before interpreting a score.

## Example

A reader checks attribute completeness before comparing presence percentages.

## Assistant Guidance

Prefer the report's current glossary over inferred definitions.
