# What does the intersection quality metric measure?

## Short Answer

The IXN quality metric indicates how many usable crossing movements an intersection's mapped network supports.

## Significance

It helps locate intersections that may need verification or design attention.

## What This Means

Higher values indicate more mapped usable crossing movements within the metric's definition. Values are calculated per analysis tile and may be summarized across a jurisdiction.

## What This Does Not Mean

It is not a complete legal, safety, or field-condition rating.

## How To Use This

Interpret values with the report methodology and local context.

## Example

A low-value intersection can be selected for field review rather than automatically labeled unsafe.

## Assistant Guidance

Ask for the report version and metric definition before comparing values.
