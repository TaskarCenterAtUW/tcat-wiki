# What are QA/QC report question sections?

## Short Answer

Question sections organize a report around practical questions about inventory, attributes, connectivity, traversability, network importance, and hotspots.

## Significance

They help non-technical readers find the evidence relevant to a decision or review task.

## What This Means

A section should be read with its definitions, inputs, maps, and limitations.

## What This Does Not Mean

The section title alone does not define the calculation or establish a conclusion.

## How To Use This

Start with the question that matches the task, then verify the report's method and dataset context.

## Example

Use the connectivity section to find possible network breaks before reviewing a bottleneck list.

## Assistant Guidance

Summarize the section's question and evidence without adding unsupported conclusions.
