# How can local POIs be added to QA/QC analysis?

## Short Answer

A jurisdiction can identify important destinations missing from open-data-derived POIs for review and possible inclusion.

## Significance

Local knowledge can correct omissions that affect walkshed and hotspot interpretation.

## What This Means

Treat additions as a documented data-change request and rerun the affected analysis when appropriate.

## What This Does Not Mean

A suggestion changes neither the source dataset nor every existing report automatically.

## How To Use This

Provide the name, location, purpose, and evidence for the destination.

## Example

A city identifies a community center and park missing from the report's POI set.

## Assistant Guidance

Ask who can approve the addition and which report version is affected.
