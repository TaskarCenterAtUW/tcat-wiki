# How do I interpret QA/QC report sections?

## Short Answer

Start with provenance and inventory, then review completeness, walksheds, connectivity, and bottlenecks with their definitions and limits.

## Significance

A section answers a different question and may use a different denominator or unit.

## What This Means

Move from data context to metrics, then validate candidate findings locally.

## What This Does Not Mean

A single map or score is not the whole report.

## How To Use This

Record the dataset, version, section, metric, and assumptions for each conclusion.

## Example

A planner checks the POI scope before interpreting a Section 4 walkshed result.

## Assistant Guidance

Ask which section and decision the user is working with.
