# Who uses Workspaces?

## Short Answer

Workspaces can serve GIS editors, project managers, reviewers, developers, and mobile-contribution teams.

## Significance

Each audience needs different documentation and permissions.

## What This Means

GIS users may edit features, managers may review or export, and contributors may collect targeted answers.

## What This Does Not Mean

A user who manages a dataset necessarily needs feature-editing access.

## How To Use This

Choose documentation by role and task rather than showing every feature to everyone.

## Example

A public-works manager uses TDEI inventory tools while a GIS specialist uses Workspaces for geometry edits.

## Assistant Guidance

Ask for the user's role and desired outcome first.
