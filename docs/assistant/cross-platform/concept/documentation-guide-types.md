# What types of documentation guide TCAT users?

## Short Answer

A user manual describes a product broadly, while a tutorial or how-to guide helps a reader complete a specific goal. The manual is reference-oriented; the focused guide is task-oriented.

## Significance

Choosing the right guide helps readers find either a complete feature reference or a direct path to an outcome. It also prevents long reference pages from carrying every procedural explanation.

## What This Means

Use a user manual to explain available controls and concepts. Use a practical tutorial or how-to for a role-specific workflow, such as managing a dataset, editing geometry, reviewing contributions, or collecting data, with reference links for additional detail.

## What This Does Not Mean

A tutorial does not replace the full manual, and a manual does not need to teach every workflow step by step. The formats can link to each other.

## How To Use This

Start with the reader's goal, prerequisites, and shortest successful path. Link from a focused guide to the relevant reference sections for details or exceptions.

## Example

A Workspaces manual can document every editor control. A tutorial can separately explain how to review and export a dataset.

## Assistant Guidance

Ask whether the user needs a concept, complete reference, or task procedure before selecting a guide. Do not treat all documentation pages as interchangeable.
