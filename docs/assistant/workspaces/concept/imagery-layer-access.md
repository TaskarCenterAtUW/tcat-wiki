# What access should workspace imagery sources have?

## Short Answer

Imagery sources must be reachable by the target application and suitable for the project's redistribution and usage rights.

## Significance

A technically valid URL can still be inappropriate for a public or volunteer workflow.

## What This Means

Check provider access, licensing, authentication, and target-client support.

## What This Does Not Mean

Embedding a URL grants rights to use or redistribute its imagery.

## How To Use This

Prefer sources the project is authorized to share with intended contributors.

## Example

A public-domain raster source is selected for a volunteer mapping workspace.

## Assistant Guidance

Do not provide legal clearance; ask for licensing and access confirmation.
