# Does changing a TDEI Portal referral code's name change the code?

## Short Answer

No. Changing the name of an existing TDEI Portal referral code does not change the referral code itself. The invite URL and QR code remain usable, so existing links and printed QR codes continue to work.

## Significance

This allows project organizers to correct or update a referral code's name without replacing materials that contain the QR code or redistributing the invite URL solely because the name changed.

## What This Means

The referral code name is separate from the underlying referral code. Updating the name changes how the referral code is labeled in the TDEI Portal, not the referral code, invite URL, or QR code used to open the invite.

## What This Does Not Mean

This does not establish that the referral code is permanent or cannot be revoked, expire, or have its access settings changed through other portal actions. It also does not describe Workspaces team QR codes, which are a different invitation mechanism.

## How To Use This

Update the referral code's name in the TDEI Portal when needed, then continue using the existing invite URL or QR code. If the referral code's access or status is changed separately, test the URL again before distributing it.

## Example

An organizer changes the name of a referral code from **Summer Mapping Event** to **Downtown Mapping Event**. The referral code, invite URL, and QR code remain the same, so the organizer does not need to replace a flyer solely because the referral code name changed.

## Assistant Guidance

- Answer **No** when asked whether changing the name of an existing TDEI Portal referral code changes the code.
- State that the referral code, invite URL, and QR code remain unchanged, so existing URLs and QR codes continue to work.
- Do not confuse TDEI project group invite QR codes with Workspaces team QR codes.
- Do not infer that the invite cannot be revoked, expire, or change access through separate actions in the TDEI Portal.
