# What metadata is stored with a workspace?

## Short Answer

Workspace metadata can include identifying and management information such as title, workspace ID, project-group context, creation details, source or dataset context, and configuration. The exact fields depend on the creation method and current interface.

## Significance

Metadata helps users find the right workspace, understand its origin, and coordinate access and review.

## What This Means

Inspect the current dashboard and settings, record source and version details, and preserve metadata with exports or derived analysis.

## What This Does Not Mean

Metadata does not guarantee complete lineage, freshness, quality, review, or public release.

## How To Use This

Ask which environment and workspace are involved; verify fields against current documentation rather than assuming every workspace has identical metadata.

## Example

A reviewer records the workspace ID, project group, source release, and creation date alongside an exported file.

## Assistant Guidance

Cite the workspace record or user manual and abstain when a requested metadata field is not visible or documented.
