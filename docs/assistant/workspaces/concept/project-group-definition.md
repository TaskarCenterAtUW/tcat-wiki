# What is a project group?

## Short Answer

A project group is an organizational context in TDEI used to associate users, datasets, workspaces, and project activity according to the platform's current access model.

## Significance

Project groups help separate project ownership, membership, permissions, and data relationships.

## What This Means

Check the current portal's group membership, roles, referrals, dataset, and workspace relationships. Use the exact group identifier and permissions shown for the project.

## What This Does Not Mean

A project group is not automatically a workspace, dataset, agency, or public community, and membership does not grant every permission.

## How To Use This

Use project groups to organize access and responsibility, then inspect workspace-specific roles and dataset visibility separately.

## Example

A project group manages a dataset and gives eligible members access to a related workspace, while workspace editing permissions remain separately configured.

## Assistant Guidance

Do not infer roles or access from the group name. Cite current TDEI documentation and abstain when the group or permission state cannot be verified.
