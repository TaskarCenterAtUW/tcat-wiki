# What tools work with Workspaces?

## Short Answer

Workspaces works with the editors and external apps documented for the current product and workspace configuration. Current documentation identifies embedded Rapid, JOSM workflows, and AVIV ScoutRoute for configured mobile contributions, but support depends on permissions, connection settings, schema, and version.

## Significance

Tool compatibility determines how users edit, collect, review, and export data and which fields or workflows are available.

## What This Means

Match the tool to the task, platform, role, dataset, and required fields. Confirm the current connection and upload path with a small test before scaling work.

## What This Does Not Mean

Compatibility does not mean every tool supports every workspace or that edits are automatically published, validated, or synchronized.

## How To Use This

Use current Workspaces and editor documentation, preserve source and changeset metadata, and verify review and export behavior for the specific workspace.

## Example

A manager uses Rapid for embedded map edits, JOSM for a supported desktop workflow, and AVIV ScoutRoute for configured mobile observations, then reviews all contributions in Workspaces.

## Assistant Guidance

Do not list unverified tools or versions as supported. Ask for the workspace, editor, role, and intended action, cite current guidance, and abstain when compatibility is unknown.
