# What is Workspaces as a private OSM environment?

## Short Answer

Workspaces provides a private OSM-like editing environment for TDEI datasets. OSM-compatible tools can work through its configured endpoint.

## Significance

This reuses familiar editors while keeping project data in its workspace context.

## What This Means

Rapid, JOSM, and AVIV ScoutRoute can serve different editing or contribution roles in a workspace.

## What This Does Not Mean

Workspace edits are not automatically public OpenStreetMap edits. Review and export gates are separate from private editing.

## How To Use This

Use the workspace endpoint and supported editor configuration for the intended project.

## Example

A mapper opens a workspace in Rapid and edits only the project's dataset.

## Assistant Guidance

Distinguish private workspace data from public OSM data.
