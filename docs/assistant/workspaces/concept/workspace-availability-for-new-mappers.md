# Why might a new mapper see no available workspace?

## Short Answer

Installing AVIV ScoutRoute does not necessarily provide a local workspace or quests. A new mapper needs access to a configured project group and an available workspace.

## Significance

This explains why an app can appear empty even when the user expects nearby tasks. Workspace availability is configured rather than global by default.

## What This Means

Check project membership, app enablement, workspace coverage, and quest configuration. A referral or event-specific onboarding path may be required. A workspace can support targeted mobile contributions without granting unrestricted dataset-editing access.

## What This Does Not Mean

An empty app does not necessarily mean the installation failed or that no mapping work exists. The user may simply lack access to a configured project.

## How To Use This

Ask the project organizer for the current referral link or QR code. Confirm that the intended workspace is open and enabled for the app.

## Example

A volunteer installs the app in a city but sees no quests. After joining the campaign project group, the volunteer can see its app-enabled workspace.

## Assistant Guidance

Troubleshoot membership and configuration before recommending reinstalling the app. Ask for the project, workspace, region, and account context.
