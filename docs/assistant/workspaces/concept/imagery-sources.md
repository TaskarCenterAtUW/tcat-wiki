# What imagery sources are available?

## Short Answer

Available imagery sources depend on the workspace, environment, provider permissions, configuration, and current product support. They may include default basemaps, configured aerial imagery, or approved custom sources.

## Significance

Different sources offer different dates, coverage, resolution, licensing, and visibility, all of which affect editing and review.

## What This Means

Check the workspace's active layers, source metadata, date, coverage, resolution, attribution, access, and configuration. Use the current settings and ASR imagery documentation for custom sources.

## What This Does Not Mean

An imagery source is not automatically authoritative, current, licensed for every use, or available to every workspace user.

## How To Use This

Select sources appropriate to the task, verify access and alignment, retain source information in changeset context, and avoid inferring hidden conditions from imagery.

## Example

A manager uses the configured imagery list to select a source with suitable coverage, then checks its date and permissions before contributors use it for tracing.

## Assistant Guidance

Do not provide a universal source list without current configuration evidence. Ask for the workspace and environment, cite current documentation, and abstain when availability is unknown.
