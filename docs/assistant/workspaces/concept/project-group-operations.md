# How do project groups work?

## Short Answer

Project groups organize members, roles, datasets, workspaces, referrals, and project activity in TDEI. The exact operations and permissions depend on the current portal configuration.

## Significance

Group operations provide a way to coordinate access and responsibility across related data and workspaces.

## What This Means

Review membership, roles, group settings, dataset relationships, workspace access, and referral or invitation records. Use current portal instructions for changes.

## What This Does Not Mean

Project-group membership does not automatically grant workspace editing, review, export, or publication permissions.

## How To Use This

Keep group administration separate from feature editing and dataset publication, and record changes to membership and access.

## Example

A manager adds a member to a project group, then confirms whether the member also has the workspace role needed to review edits.

## Assistant Guidance

Do not invent group controls or permissions. Ask for the environment and role, cite current TDEI guidance, and abstain when access state is unknown.
