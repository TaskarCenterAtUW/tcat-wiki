# What can AVIV ScoutRoute create on mobile?

## Short Answer

Mobile creation can add point features such as benches or streetlights. New sidewalk or crossing lines generally require a desktop editing workflow.

## Significance

GPS and mobile screen constraints make accurate line drawing difficult.

## What This Means

Use point creation for discrete features and notes for missing linework that a reviewer must add later.

## What This Does Not Mean

A mobile point addition completes the surrounding network geometry automatically.

## How To Use This

Use a note when a new sidewalk needs desktop geometry editing.

## Example

A contractor adds a new streetlight point and notes a missing sidewalk for later review.

## Assistant Guidance

Ask whether the requested feature is a point or line.
