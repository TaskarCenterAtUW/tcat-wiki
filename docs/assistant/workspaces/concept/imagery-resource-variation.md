# Why do imagery resources differ between workspaces?

## Short Answer

Imagery resources can differ between workspaces because managers configure different sources, areas, dates, permissions, schemas, or project needs. Environment and application settings can also affect availability.

## Significance

Variation reflects workspace-specific context and does not necessarily indicate inconsistent editable data.

## What This Means

Check each workspace's imagery definition, source, date, coverage, permissions, attribution, and active layers before comparing images or edits.

## What This Does Not Mean

Different imagery resources do not prove that one workspace is more accurate or that sources are interchangeable.

## How To Use This

Record the imagery used for an edit or review and verify alignment and currency for the specific workspace.

## Example

A city workspace uses a licensed local aerial layer while a community workspace uses a different public source; reviewers retain both source contexts.

## Assistant Guidance

Do not infer a cause without configuration evidence. Ask for workspace and source details, cite current settings guidance, and abstain when availability or permission is unclear.
