# How does Workspaces support stewardship?

## Short Answer

Workspaces supports stewardship by giving teams a shared editing environment, role-based collaboration, review checkpoints, source lineage, and controlled export paths.

## Significance

These capabilities help jurisdictions and communities maintain accessibility data as an ongoing responsibility rather than a one-time mapping exercise.

## What This Means

Define roles, record sources, coordinate edits, review changes, resolve issues, and publish only through the responsible governance process.

## What This Does Not Mean

Workspaces does not replace local authority, field validation, maintenance funding, or publication policy.

## How To Use This

Use Workspaces as one part of a stewardship program and document the responsible jurisdiction, dataset, and review path.

## Example

A jurisdiction invites community contributors to identify missing curb ramps, then has an authorized reviewer validate and export the accepted changes.

## Assistant Guidance

Cite the relevant workflow and state which responsibilities remain with the data steward.
