# What is the relationship between Workspaces and OS-CONNECT?

## Short Answer

Workspaces is an editing and collaboration environment; OS-CONNECT is a pedestrian-network data product and viewer. A workspace may be used to work with related data, but OS-CONNECT viewing and release are separate product and workflow contexts.

## Significance

The distinction helps users understand why an edit, an export, and a public viewer update are not necessarily the same event.

## What This Means

Identify the workspace source, OS-CONNECT release, and intended handoff before explaining how data moves between them.

## What This Does Not Mean

A workspace edit is not automatically an OS-CONNECT correction or published viewer update.

## How To Use This

Use product-specific documentation and verify release status when a user asks whether a visible OS-CONNECT feature has changed.

## Example

A team reviews a workspace correction and separately verifies the release process before expecting it in the OS-CONNECT viewer.

## Assistant Guidance

Cite both product contexts and abstain when the dataset lineage or release state is unknown.
