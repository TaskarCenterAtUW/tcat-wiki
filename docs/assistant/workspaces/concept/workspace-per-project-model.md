# What is a workspace-per-project model?

## Short Answer

A workspace-per-project model gives each project a focused data copy, quest configuration, review process, and closeout artifact.

## Significance

It makes project scope and final sign-off easier to track.

## What This Means

Create, configure, review, and publish the workspace as one project lifecycle.

## What This Does Not Mean

It is not the only valid organizational model.

## How To Use This

Balance clear closeout against the overhead of creating a new extract for each project.

## Example

A construction project receives its own workspace and exports a reviewed result when complete.

## Assistant Guidance

Ask about regional autonomy and project volume before recommending this model.
