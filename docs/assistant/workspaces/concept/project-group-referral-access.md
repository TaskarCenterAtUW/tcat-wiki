# How do project-group referrals provide workspace access?

## Short Answer

A project-group referral code or QR code can associate a new TDEI account with a specified project group. If that group has an available workspace, the user can then access the configured project tools.

## Significance

Referral access gives an event or campaign a controlled onboarding path. It is more specific than simply telling people to download an app.

## What This Means

Provide the current referral code before registration, then verify that the project group contains the intended service, workspace, and app configuration. If the user was separated from the original referral flow, they may be able to join through the portal's user menu. Users may still need a separate team-joining step; referral onboarding does not complete publication.

## What This Does Not Mean

Project-group membership does not automatically grant access to every workspace, team, or product feature. Referral behavior depends on current project configuration.

## How To Use This

Test the referral path before an event and give users clear instructions for what happens after registration. Keep project-group and team codes distinct.

## Example

An event flyer includes a project-group QR code. A participant registers through it and is associated with the campaign group, where an app-enabled workspace is available.

## Assistant Guidance

Ask whether the code is for a TDEI project group or a Workspaces team. Do not claim that the two referral mechanisms are interchangeable.
