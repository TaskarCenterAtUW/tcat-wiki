# What is RAPID?

## Short Answer

Rapid is a fast web-based OpenStreetMap editor; a modified version is embedded in Workspaces for editing open workspaces. It provides an editor interface, not an automatic quality or publication decision.

## Significance

Rapid can lower the barrier to targeted accessibility edits while preserving the need for source evidence, appropriate permissions, and review.

## What This Means

Choose Rapid for supported web editing, inspect tags and imagery, and follow the target workspace's review and export process.

## What This Does Not Mean

Rapid does not guarantee that an edit is correct, reviewed, accepted, or visible in another dataset.

## How To Use This

Confirm whether the user is editing OpenStreetMap or a Workspaces dataset before describing save, permission, or synchronization behavior.

## Example

A mapper adds a sidewalk feature in the embedded Rapid editor, checks its tags, and submits it for the workspace's review workflow.

## Assistant Guidance

Cite the applicable Rapid or Workspaces documentation. Do not infer permissions or publication outcomes from the editor name.
