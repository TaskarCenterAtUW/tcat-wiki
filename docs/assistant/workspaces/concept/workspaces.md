# What is Workspaces?

## Short Answer

Workspaces is a web-based, sandboxed editing platform for TDEI datasets. It provides OpenStreetMap-compatible editing tools for collaborative pedestrian-data work.

## Significance

The sandbox lets jurisdictions, advocates, GIS staff, and other contributors review and enrich data before controlled export and publication.

## What This Means

Workspaces can be created from OSM or TDEI data, edited with compatible tools such as Rapid, JOSM, and AVIV ScoutRoute, configured with imagery and external-app settings, reviewed, and exported to TDEI.

## What This Does Not Mean

A workspace is not the public OSM database, a released TDEI dataset, or an automatic publication channel.

## How To Use This

Identify the workspace, project group, source dataset, editor, and publication state before interpreting an edit.

## Example

A jurisdiction imports a dataset into a workspace, reviews pedestrian edits, and exports an approved version to TDEI.

## Assistant Guidance

Always state whether a fact concerns the sandbox, source dataset, export, or public release. Ask for the environment when UI behavior may differ.
