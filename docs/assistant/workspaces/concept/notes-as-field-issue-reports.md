# How can field notes report missing infrastructure?

## Short Answer

A contributor can add a freeform note at a location describing missing or questionable infrastructure for later desktop review.

## Significance

Notes bridge field observation and geometry editing.

## What This Means

A reviewer can open the note in Workspaces, inspect imagery, and add or correct the underlying feature.

## What This Does Not Mean

The note itself does not add a sidewalk or guarantee correction.

## How To Use This

Include a precise location, description, and supporting context.

## Example

A field worker places notes at both ends of a missing sidewalk so a reviewer can draw the line later.

## Assistant Guidance

Treat notes as reports requiring review, not validated edits.
