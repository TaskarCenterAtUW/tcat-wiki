# What is JOSM?

## Short Answer

JOSM, the Java OpenStreetMap Editor, is a desktop editor used for detailed OpenStreetMap work and supported Workspaces workflows where the connection, permissions, and data format are configured appropriately.

## Significance

JOSM provides detailed editing and validation tools that may suit complex geometry or experienced contributors.

## What This Means

Check the current Workspaces connection instructions, editor version, authentication, data source, schema, and upload or review path before editing.

## What This Does Not Mean

JOSM edits are not automatically published to OpenStreetMap, TDEI, or OS-CONNECT in every workflow. Editor validation does not replace local or field evidence.

## How To Use This

Use JOSM for supported tasks, preserve source and changeset context, validate edits, and follow the workspace's review and export process.

## Example

A GIS contributor uses JOSM for detailed geometry work in a configured workspace, records the source, and submits the changes for review before export.

## Assistant Guidance

Do not promise JOSM compatibility or controls without checking the current environment. Ask for the workspace and task, cite current guidance, and abstain when connection details are unknown.
