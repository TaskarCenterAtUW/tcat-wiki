# Why are vector maps preferred for accessibility editing?

## Short Answer

Vector maps are often preferred for accessibility editing because features and attributes can be represented as selectable data rather than only as pixels. Preference depends on the task and does not make the basemap authoritative.

## Significance

Selectable geometry and visible attributes can help a mapper inspect and edit features precisely, while imagery remains useful as visual evidence.

## What This Means

Use vector data for feature interaction when available, and compare it with imagery, field evidence, and source metadata.

## What This Does Not Mean

Vector display does not guarantee complete, current, correctly tagged, or editable data.

## How To Use This

Choose the layer based on the editing task, source, date, and access. Keep the distinction between display and authoritative data.

## Example

A mapper selects a vector sidewalk feature to inspect its tags and uses aerial imagery only to check visible alignment.

## Assistant Guidance

Cite layer and dataset documentation; abstain when the source or editability of a layer is unknown.
