# What sources can create a workspace?

## Short Answer

A workspace can be created from a TDEI dataset, a blank workspace, or a supported local OpenSidewalks file.

## Significance

These options support both managed datasets and new or imported work.

## What This Means

Choose the source that matches the project's lineage and intended scope.

## What This Does Not Mean

A blank or local workspace is not automatically linked to a public release.

## How To Use This

Confirm project group, format, source file, and environment before creating it.

## Example

A converted OSW ZIP file is used to create a workspace for an area downloaded from OSM.

## Assistant Guidance

Ask for the source type and intended output before giving steps.
