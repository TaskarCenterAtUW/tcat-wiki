# How can users continue editing an existing feature?

## Short Answer

Users can continue editing an existing feature by locating it in the correct workspace, checking its current geometry, attributes, history, and review status, then making a supported evidence-based change and saving it in a new reviewable edit.

## Significance

Continuing an edit requires understanding prior changes so that contributors do not overwrite valid work, duplicate features, or lose source context.

## What This Means

Identify the workspace and feature, inspect existing changesets and notes, check current source evidence, coordinate with other contributors, make the smallest supported change, and document the new source and reason.

## What This Does Not Mean

Opening a feature does not prove that its existing values are correct or that a user may change every field. A new edit does not automatically resolve earlier review issues or publish the feature.

## How To Use This

Use the current editor and review interface, preserve history, avoid conflicting concurrent edits, and request clarification when the prior source or intended change is unclear.

## Example

A mapper opens an existing sidewalk, reviews its previous source and pending notes, updates a supported surface value from a new observation, and uploads a changeset comment.

## Assistant Guidance

Ask for the workspace, feature, editor, and review state. Do not advise overwriting uncertain data, and abstain when history or permissions cannot be verified.
