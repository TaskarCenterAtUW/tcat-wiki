# How can I export workspace data to a local file?

## Short Answer

Use the workspace export function or current export utility to save workspace data locally without sending it to TDEI.

## Significance

Local export supports developer inspection and use in other tools.

## What This Means

Choose the desired output format and preserve the workspace source and version.

## What This Does Not Mean

A local export does not publish or synchronize the workspace.

## How To Use This

Use the current utility instructions and protect any private data.

## Example

A developer exports a workspace as OSM to inspect it in another editor.

## Assistant Guidance

Ask which format and environment are involved before giving command details.
