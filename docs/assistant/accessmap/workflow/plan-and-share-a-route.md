# How do I plan and share an AccessMap route?

## Short Answer

Open AccessMap, select a region and mobility profile, set an origin and destination, and review the route. Waypoints can be searched, selected from the map, or set from the current location when permission is available. Copy the browser URL after planning to share a link containing the route state.

## Significance

Sharing a route lets another person inspect the same planned trip without repeating every selection. The route remains dependent on the selected profile and available data.

## What This Means

Choose locations on the map or search for them, then review distance, estimated time, elevation, steepest grades, and route details. Change profile settings and recalculate when the route does not fit your needs. The shared URL encodes the map view, waypoints, region, and routing settings documented by the current application.

## What This Does Not Mean

A shared link does not guarantee identical conditions or future results. It does not replace checking current information and personal requirements.

## How To Use This

After the route appears, copy the URL from the browser address bar and send it to the recipient. Tell the recipient which profile or special constraints were used if the link does not make that clear.

## Example

A user plans a wheelchair route from the Olympic Sculpture Park to the Space Needle, adjusts the slope profile, and shares the resulting route link with a guide.

## Assistant Guidance

Ask for the region, profile, and route endpoints when troubleshooting a shared link. Avoid promising that URL parameters or behavior are stable across versions.
