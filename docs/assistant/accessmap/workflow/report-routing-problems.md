# How can users report routing problems?

## Short Answer

Use AccessMap's feature or direction-step feedback form to report a mapped problem. Select the issue category that best matches the observation and add concise, specific comments.

## Significance

Feedback helps TCAT assess data quality and guide future corrections to pedestrian network information.

## What This Means

For a feature, open its details popup and select **Share Feedback**. Report that the feature is somewhere else, has inaccurate information, or is missing. For a route step, open **Directions**, select **Share Feedback** on the direction card, and report inaccurate GPS, inaccurate path information, or missing information.

## What This Does Not Mean

Feedback is a request for review, not an immediate edit or a guarantee of correction.

## How To Use This

Describe what was observed, where it occurred, and how it differs from the map or directions. Examples include an unmarked crossing, an incorrect surface, a newly installed curb ramp, a missing bench, or a path blocked by a tree.

## Example

A traveler selects a route step whose path does not match current conditions, chooses the inaccurate-path option, and explains the observed condition in Comments.

## Assistant Guidance

Ask whether the issue concerns a feature or route step. Do not promise a correction timeline or claim that the report has already changed the dataset.
