# How do I get AccessMap set up for my region?

## Short Answer

Attend a weekly TCAT Office Hours meeting and make the request to set up AccessMap support for your region. Be prepared to identify a decent-quality pedestrian network data source for the location, either from OpenStreetMap (OSM) or in a local data portal dataset.

## Significance

TCAT needs both a request from people working in or for the region and suitable pedestrian network data to evaluate AccessMap support for a location.

## What This Means

1. Attend a weekly TCAT Office Hours meeting.
2. Make the request for AccessMap support for your region.
3. Identify whether the region has decent-quality pedestrian network data in OSM or in another local data source.
4. Share information about the relevant data source during the discussion.

The data source should model the pedestrian network well enough for TCAT to assess whether it can support AccessMap routing for the region.

## What This Does Not Mean

Attending Office Hours is the way to make the request, but it does not guarantee that AccessMap support will be enabled. The presence of data in OSM or a local source does not by itself confirm that the data is suitable or ready for AccessMap.

## How To Use This

Before attending Office Hours, identify the region you want to support and the pedestrian network data available there. If the data is in OSM, identify the relevant mapped area. If it is in a local data source, identify the organization or program that maintains it, the license under which it is made available, and be ready to describe the source.

## Example

A local accessibility advocate wants AccessMap support for their city. They attend a weekly TCAT Office Hours meeting, request support for the city, and explain that the city's pedestrian network is mapped in OSM. TCAT can then discuss the data and the regional request.

## Assistant Guidance

Tell the requester to attend a weekly TCAT Office Hours meeting and make their request. Ask which region they want to support and whether decent-quality pedestrian network data is available in OSM or a local data source. Do not promise that TCAT will enable support, and do not treat the existence of a dataset as proof that it is suitable for AccessMap.
