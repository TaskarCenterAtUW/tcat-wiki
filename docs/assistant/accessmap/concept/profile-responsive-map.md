# How does AccessMap respond to mobility profiles?

## Short Answer

AccessMap changes its route and map display according to the selected mobility profile and preferences. Slope, barriers, and other constraints can make features appear more or less suitable for that traveler.

## Significance

The map is not only a static inventory. It helps users interpret the network according to their own mobility needs.

## What This Means

Adjust profile settings such as slope limits, then review the updated colors and route results. The incline bar and path colors update with the selected maximum uphill and downhill settings. A feature may be usable for one profile and unsuitable for another.

## What This Does Not Mean

A profile-based display is not a universal accessibility judgment. It does not describe every person's needs or guarantee a route's real-world suitability.

## How To Use This

Choose the closest available profile and customize it when needed. Treat the result as decision support and check conditions that may not be represented.

## Example

Lowering the permitted uphill grade causes steeper segments to appear restricted and can produce a different route.

## Assistant Guidance

Ask which profile and settings were used before comparing routes. Do not describe a color or route as universally accessible.
