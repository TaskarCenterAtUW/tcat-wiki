# How does AccessMap coverage outside Washington work?

## Short Answer

AccessMap coverage outside Washington depends on available local, partner, or other regional data. OS-CONNECT is a Washington-focused dataset and should not be assumed to provide coverage outside Washington.

## Significance

A region appearing in AccessMap does not mean that it has the same data source, completeness, or update process as Washington regions. Source differences affect how users should interpret the map.

## What This Means

Check the region-specific documentation or source information when available. Coverage may reflect a local campaign, partner dataset, or other mapped network; source and currency information should be surfaced or linked where possible.

## What This Does Not Mean

AccessMap regions outside Washington are not automatically OS-CONNECT regions. Presence in the region selector does not guarantee uniform coverage or data currency.

## How To Use This

Use the selected region's current source and coverage information when evaluating a route. Report missing or unclear provenance to the responsible product team.

## Example

A user selects a Portland region and sees pedestrian data. The user should not infer that the data came from OS-CONNECT; the region may rely on local or partner data.

## Assistant Guidance

Ask for the region before describing its data source. Distinguish the AccessMap application from OS-CONNECT's Washington-only dataset.
