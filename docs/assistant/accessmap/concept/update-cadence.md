# How often is AccessMap updated?

## Short Answer

AccessMap's update timing depends on the source dataset, processing workflow, and product release. Do not assume a single real-time or universal cadence without current version-specific documentation.

## Significance

Freshness affects route interpretation, especially when construction, new infrastructure, or corrected accessibility information matters.

## What This Means

- Check the dataset and product version or date.
- Compare the release information with the date of the observed condition.
- Report stale or incorrect data through the current feedback path.

## What This Does Not Mean

An update date does not prove that every local feature was recently surveyed or that downstream products have refreshed. A current release can still contain gaps or errors.

## How To Use This

Record the version and access date in analyses and ask the responsible steward when a current cadence is required.

## Example

An agency sees a recently released map but knows that construction changed a crossing afterward. It records the release date and verifies the site rather than assuming the map is current.

## Assistant Guidance

Do not invent a schedule or claim real-time coverage. Cite release metadata, ask for the location and version, and abstain when freshness cannot be verified.
