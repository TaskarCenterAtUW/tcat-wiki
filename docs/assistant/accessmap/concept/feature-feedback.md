# How can I submit feedback about an AccessMap feature?

## Short Answer

Use the feature or direction feedback control to report a misplaced feature, inaccurate information, or missing information. Feature feedback covers map objects such as sidewalks, crossings, curb ramps, and landmarks; direction feedback covers a specific planned-route step. Add concise comments when they help explain the problem.

## Significance

Specific feedback helps maintain the data used for accessible routing. Reports can identify both individual feature errors and route-level problems.

## What This Means

Select the affected feature or direction card, choose the applicable feedback category, and describe the issue. Feature categories include a feature being somewhere else, inaccurate information, or something missing. Direction-step categories include inaccurate GPS, an inaccurate path, or something missing. The report is a request for review, not an immediate data edit.

## What This Does Not Mean

Feedback does not guarantee that the report is correct, accepted, or fixed immediately. The underlying source and review process determine the outcome.

## How To Use This

Include the location, observed condition, and relevant route or profile. Keep comments factual and specific, such as noting an unmarked crossing, a gravel surface, a newly installed curb ramp, a missing bench, or a path blocked by a tree.

## Example

A user sees a curb ramp marked incorrectly, selects feature feedback, chooses inaccurate information, and describes the observed condition.

## Assistant Guidance

Ask whether the issue concerns a feature, route, or missing data. Do not promise a correction timeline.
