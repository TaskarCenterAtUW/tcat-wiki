# Can AccessMap support powered wheelchair users?

## Short Answer

AccessMap can support powered wheelchair-oriented route planning through a relevant mobility profile and available pedestrian accessibility data. Results are model-based and depend on the current profile, network, and mapped attributes.

## Significance

Powered wheelchair users may need different route considerations from general walking users. A profile helps make some route tradeoffs explicit.

## What This Means

- Select the current powered-wheelchair profile or closest documented option.
- Review the assumptions and relevant accessibility attributes.
- Verify surface, clearance, construction, and crossing conditions locally.

## What This Does Not Mean

Profile support is not a guarantee that a route fits a particular device or is safe, comfortable, or legally compliant. It does not replace personal judgment or field verification.

## How To Use This

Ask for the profile and product version, state the data limitations, and cite current AccessMap guidance.

## Example

A powered wheelchair user compares routes under a relevant profile, then checks a narrow passage and current construction conditions before traveling.

## Assistant Guidance

Do not infer device requirements or promise route usability. Cite the profile documentation and abstain when the current settings or local conditions are unknown.
