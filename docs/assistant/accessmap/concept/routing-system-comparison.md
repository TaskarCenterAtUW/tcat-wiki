# How can agencies compare routing systems?

## Short Answer

Agencies can compare routing systems by defining the use case, holding origins and destinations constant, recording profiles and data versions, and evaluating results against field or authoritative reference information. The comparison should use criteria relevant to the decision.

## Significance

Different systems optimize different objectives and may use different sources. A transparent comparison is more useful than a simple route-length ranking.

## What This Means

- Define accessibility, coverage, instruction, or operational criteria.
- Compare equivalent settings and document source versions.
- Review route differences with local observations and affected users.

## What This Does Not Mean

No system is universally correct, and a shorter route is not automatically better or more accessible. A comparison does not establish legal compliance.

## How To Use This

Publish the method, criteria, sample, and limitations with the result.

## Example

An agency tests three products on representative trips, using documented profiles and field observations to compare connectivity, slope, curb-ramp handling, and instructions.

## Assistant Guidance

Ask what decision and criteria matter. Cite each product and dataset, avoid unsupported rankings, and abstain when the comparison inputs are not equivalent.
