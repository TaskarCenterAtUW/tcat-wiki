# Can communities define accessibility priorities?

## Short Answer

Communities can help define which accessibility considerations matter for a routing or planning discussion, such as slopes, curb ramps, surfaces, or crossings. Those priorities should be documented and interpreted as inputs to a model, not as a universal definition of access.

## Significance

Community priorities make route analysis more responsive to lived experience and local needs. They also reveal where a default profile may not fit the people using the network.

## What This Means

- Invite affected people to describe relevant barriers and tradeoffs.
- Translate the agreed priorities into documented profile or analysis settings when supported.
- Review results with the community and verify important locations.

## What This Does Not Mean

Community input does not automatically change AccessMap, guarantee a configuration, or establish legal compliance. One priority set cannot represent every traveler.

## How To Use This

Record who participated, what was prioritized, and which model settings were used. Keep unresolved disagreements visible.

## Example

A disability community identifies missing curb-ramp information as a high-priority concern, and planners compare routes using a documented preference before checking key crossings locally.

## Assistant Guidance

Do not claim that one profile represents the community as a whole. Cite the settings and engagement record, and abstain when participation or configuration details are missing.
