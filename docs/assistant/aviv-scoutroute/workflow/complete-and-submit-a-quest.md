# How do I complete and submit an AVIV ScoutRoute quest?

## Short Answer

Zoom in to find a quest, open it, observe the highlighted feature, answer the configured questions, review the response, and select **Submit**.

## Significance

This workflow turns a direct field observation into a targeted project contribution.

## What This Means

Quest icons may stack when zoomed out. After opening a quest, read its instructions, inspect the feature, use the requested input type and unit, and select **Submit** when the answer is ready. The completed quest then disappears from the map.

## What This Does Not Mean

Submission does not prove that the answer is correct, remove the need for review, or publish the entire dataset.

## How To Use This

Use Unknown or skip when the feature cannot be determined, and review all selected options before submitting. Use group selection only when every selected feature has the same characteristics.

## Example

A contributor zooms in, opens a crossing quest, observes the markings and signals, selects all applicable options, reviews the response, and submits it.

## Assistant Guidance

Ask which quest type and input control are involved. Encourage direct observation and do not advise guessing.
