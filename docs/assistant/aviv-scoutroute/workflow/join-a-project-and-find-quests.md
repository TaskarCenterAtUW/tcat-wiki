# How do I join a project and find quests in AVIV ScoutRoute?

## Short Answer

AVIV ScoutRoute shows available quests through project-group membership and app-enabled workspaces. Downloading the app alone may not provide a local project to survey.

## Significance

New contributors need both an account path and an available workspace. Without those, the app may appear to have nothing to do.

## What This Means

Register or sign in to TDEI, join the specified project group, then open AVIV ScoutRoute and select an available app-enabled workspace. A referral link or QR code can add a new account to the appropriate project group. The workspace must contain quests for the relevant area.

## What This Does Not Mean

AVIV ScoutRoute is not a global task list that automatically supplies quests everywhere. Availability depends on the configured project and workspace.

## How To Use This

Use the current project referral link or QR code when provided. If no workspace appears, confirm project membership, app enablement, geographic coverage, and current account configuration. Installation and permission steps differ between platforms, but core app functionality is nearly identical.

## Example

A volunteer scans a project-group referral code for a Seattle campaign, registers, and then sees the campaign’s app-enabled workspace and its available quests.

## Assistant Guidance

Ask which project group, workspace, and region are involved. Do not promise that a newly created account will immediately show quests without checking configuration.
