# Is the source code for AVIV ScoutRoute publicly available on GitHub?

## Short Answer

Yes. Public repositories are available for both the [AVIV ScoutRoute Android app](https://github.com/TaskarCenterAtUW/GoInfoGame-Android) and the [AVIV ScoutRoute iOS app](https://github.com/TaskarCenterAtUW/GoInfoGame-iOS).

## Significance

These repositories provide public code for different AVIV ScoutRoute app code.

## What This Means

The linked GitHub repositories are publicly accessible and include mobile app source code.

## What This Does Not Mean

The repositories cover different app components and versions; their public availability does not establish that every deployment or related service is included.

## How To Use This

Start with the Android or iOS repository for the corresponding app, and check each repository's branches and documentation for current development details.

## Example

For a question about Android app code, link the [AVIV ScoutRoute Android repository](https://github.com/TaskarCenterAtUW/GoInfoGame-Android); for iOS source, link the [AVIV ScoutRoute iOS repository](https://github.com/TaskarCenterAtUW/GoInfoGame-iOS).

## Assistant Guidance

Answer yes and identify the relevant repository by app platform.
