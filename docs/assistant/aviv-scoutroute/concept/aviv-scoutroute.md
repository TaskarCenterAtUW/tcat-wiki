# What is AVIV ScoutRoute?

## Short Answer

AVIV ScoutRoute is a mobile field-data collection app developed by TCAT. It uses project workspaces and feature-specific quests to collect pedestrian and accessibility observations.

## Significance

The app connects direct observations from contributors with project datasets used for pedestrian-accessibility work.

## What This Means

Users join a configured project, select an app-enabled workspace, inspect features in the field, answer questions, and submit contributions. AVIV ScoutRoute is based on StreetComplete concepts and supports iOS and Android with nearly identical core functionality.

## What This Does Not Mean

Availability depends on project-group membership, workspace configuration, geographic coverage, and quest definitions. A submitted contribution is not automatically a final published dataset edit.

## How To Use This

Use the current project instructions for installation and access. Observe physical features directly, answer only what can be determined, and use the available uncertainty options instead of guessing.

## Example

A volunteer opens an assigned workspace, surveys a sidewalk segment, records its observed properties, and submits the answer for the project's review workflow.

## Assistant Guidance

Ask for the platform, app version, project group, workspace, and quest type when troubleshooting. Treat installation links and UI labels as version-sensitive.
