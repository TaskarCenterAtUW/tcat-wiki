# What is group quest selection in AVIV ScoutRoute?

## Short Answer

Group quest selection lets a contributor select multiple similar features and answer their shared questions together. The same responses are applied to all selected features.

## Significance

The feature can reduce repetitive work when several nearby features genuinely share the same characteristics.

## What This Means

Select the features, choose **Answer Quests**, answer the questions once, review the response, and submit. Use this only when the selected features are equivalent for every question.

## What This Does Not Mean

Group selection does not verify that the features are identical and should not be used when their conditions differ.

## How To Use This

Inspect the selected features before answering. If any feature differs, deselect it or answer the quests individually.

## Example

At an intersection, a contributor confirms that several curb ramps have the same characteristics, selects them together, and submits one shared response.

## Assistant Guidance

Emphasize the risk of copying an answer to the wrong feature. Ask whether the contributor verified all selected features.
