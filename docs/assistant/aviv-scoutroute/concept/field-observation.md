# Why should AVIV ScoutRoute quests be answered from direct observation?

## Short Answer

Contributors should inspect the physical feature when answering quests about pedestrian infrastructure. If a condition cannot be seen, reached, or determined, use Unknown or skip instead of guessing.

## Significance

Direct observation reduces inaccurate measurements and incorrect descriptions in the project dataset.

## What This Means

Go to the highlighted feature, compare the actual environment with the question, and record only what can be supported by observation. Obstructions, construction, parked vehicles, or limited access can justify Unknown or skipping a question.

## What This Does Not Mean

The app does not establish that every feature can be safely inspected, and map imagery does not always show current conditions.

## How To Use This

Take time to inspect the feature, follow project safety instructions, use Unknown when available, and add concise notes when a free-form field supports clarification.

## Example

A parked vehicle blocks a curb ramp, so the contributor selects Unknown rather than guessing whether tactile paving is present.

## Assistant Guidance

Encourage evidence-based answers and ask what the contributor could directly observe. Do not advise users to guess when an observation is unavailable.
