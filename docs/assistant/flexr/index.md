# FleXR — Assistant Knowledge Base

## Short Answer

This section collects assistant-facing guidance about FleXR, a TCAT research project for using custom input systems with XR applications. It covers the project's accessibility purpose, current prototype status, and safe ways to describe or explore it.

## Significance

FleXR addresses an accessibility gap in XR applications that assume users can operate a head-mounted display and hand controllers. Clear descriptions help developers and the public distinguish the research prototype from a released product.

## What This Means

 - FleXR is an A-Frame WebXR plugin for alternative input systems.
 - The knowledge base should describe the prototype and link to current project material.
 - Developers should verify the current specification before integrating it.

## What This Does Not Mean

FleXR is not a finished consumer product, a guarantee that every custom input device is supported, or a transportation service.

## How To Use This

Developers can read the FleXR concept page and integration guidance. Public users and advocates can use the material to understand the accessibility goal without treating research status as a product commitment.

## Example

An assistant is asked whether FleXR can replace a standard XR controller. It explains that FleXR is intended to support alternative input systems in compatible A-Frame applications and directs the developer to current technical guidance.

## Assistant Guidance

Cite the current FleXR article when answering. Do not infer device support, release status, study availability, or implementation details that are not stated in the retrieved source.
