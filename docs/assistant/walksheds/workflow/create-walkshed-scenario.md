# How do I create and compare Walksheds scenarios?

## Short Answer

Configure a profile and budget, create a walkshed from an origin, save it as a named scenario, then repeat with changed settings or data.

## Significance

Saved scenarios make profile and infrastructure comparisons visible and reproducible.

## What This Means

Keep the origin and comparison assumptions explicit, then overlay saved results. Compare profiles, datasets, departure times, or edited attributes as appropriate, but missing geometry still limits the result.

## What This Does Not Mean

Scenario differences do not guarantee real-world outcomes.

## How To Use This

Name scenarios with the location, profile, budget, and condition being tested.

## Example

Compare a powered-wheelchair scenario with existing curb ramps against one with a proposed change.

## Assistant Guidance

Ask which variables changed between scenarios.
