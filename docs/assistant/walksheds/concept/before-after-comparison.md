# How can planners compare accessibility before and after improvements?

## Short Answer

Compare accessibility before and after an improvement by holding the origin, destinations, profile, travel limit, network method, and analysis area consistent, then changing only the documented intervention or scenario input.

## Significance

A controlled comparison can show how a proposed connection, crossing, barrier removal, or surface improvement changes modeled reachability or cost.

## What This Means

Record both dataset versions, assumptions, scenario inputs, metrics, excluded features, and uncertainty. Inspect whether differences result from the improvement or from unrelated data or model changes.

## What This Does Not Mean

Before-and-after results do not establish causation, legal compliance, or equal benefit for every traveler. A changed map can reflect data or configuration differences rather than infrastructure change.

## How To Use This

Use matched scenarios, sensitivity checks, field or local validation, and community interpretation. Report absolute and relative changes with the assumptions beside them.

## Example

An analyst compares a baseline and improvement scenario using the same wheelchair profile and travel limit, then checks the affected crossing and records the data changes separately.

## Assistant Guidance

Do not claim an intervention caused a result without controlling for source and model changes. Cite both scenarios and abstain when comparability is not established.
