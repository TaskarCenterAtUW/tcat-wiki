# What is the Walksheds edit history?

## Short Answer

The edits view lists changed attributes and can provide a way to review or restore them.

## Significance

It helps distinguish temporary scenario changes from source-data changes.

## What This Means

Review the changed feature and original value before deleting an edit.

## What This Does Not Mean

The edit history is not the source dataset's permanent change history.

## How To Use This

Record failed deletion or restoration behavior as a product issue.

## Example

A planner removes a temporary curb-ramp edit to restore the original scenario.

## Assistant Guidance

Clarify whether an edit is temporary, saved in a scenario, or published elsewhere.
