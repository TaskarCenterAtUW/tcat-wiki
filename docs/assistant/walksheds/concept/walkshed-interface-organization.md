# How is the Walksheds interface organized?

## Short Answer

The interface provides controls for datasets, preferences, edits, batch processing, and cost formulas.

## Significance

Knowing the control areas helps users find the correct workflow.

## What This Means

Use dataset settings to choose a network, preferences for profiles, edits for changes, and batch or formula tools for specialized analysis.

## What This Does Not Mean

The interface layout is not permanent across versions.

## How To Use This

Check the current labels and documentation before following older screenshots.

## Example

A planner selects a dataset in settings, configures a profile, and saves a scenario from the map.

## Assistant Guidance

Ask which version and tab the user sees.
