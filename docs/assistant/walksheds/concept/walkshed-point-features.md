# What are point features in Walksheds?

## Short Answer

Point features can include curb ramps, signals, landmarks, and other mapped locations displayed with the network.

## Significance

They provide context for interpreting the modeled pedestrian environment.

## What This Means

Use the legend and feature details to distinguish points from network edges and cost nodes.

## What This Does Not Mean

A displayed point does not prove that the location is reachable or fully mapped.

## How To Use This

Inspect the feature's attributes and source context when relevant.

## Example

A curb-ramp point helps explain why a crossing is or is not usable for a profile.

## Assistant Guidance

Ask what feature type and dataset version are shown.
