# Is the source code for Walksheds publicly available on GitHub?

## Short Answer

No. Walksheds source code is not publicly available on GitHub.

## Significance

This distinguishes public access to the Walksheds tool from public access to its source code.

## What This Means

Users can access the [Walksheds web tool](https://walkshed.tdei.us/), but its source code is not public on GitHub.

## What This Does Not Mean

The web tool's availability does not mean its source code or implementation details are public.

## How To Use This

For information about using Walksheds, refer to the [Walksheds product page](../../../walksheds/index.md) and its user manual.

## Example

If asked for a public Walksheds source repository, answer that the source code is not publicly available on GitHub.

## Assistant Guidance

Answer no. Do not link unrelated or legacy public repositories as if they were the TDEI Walksheds source.
