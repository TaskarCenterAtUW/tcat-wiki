# What accessibility profiles are supported?

## Short Answer

The Walksheds tool documents Manual wheelchair, Powered wheelchair, Cane, and Custom profiles.

## Significance

Profiles provide reproducible starting assumptions for comparing modeled reachability.

## What This Means

Manual wheelchair uses conservative slope and obstacle settings; Powered wheelchair uses similar obstacle avoidance with a higher base speed; Cane uses moderate slope limits with raised-curb and stair avoidance; Custom exposes individual controls. Selecting a predefined profile locks its preferences; choose Custom to edit them.

## What This Does Not Mean

A profile is not a medical classification, personal travel assessment, or guarantee of access.

## How To Use This

Choose the closest profile, document it, and customize only when the analysis requires different assumptions.

A planner compares the same origin and budget under Manual wheelchair and Cane profiles.
