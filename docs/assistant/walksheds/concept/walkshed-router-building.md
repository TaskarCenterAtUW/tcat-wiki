# What does building a Walksheds router do?

## Short Answer

Building a router prepares a selected pedestrian network for walkshed calculations.

## Significance

Processing occurs on TCAT infrastructure and may take longer for larger networks.

## What This Means

Select the intended dataset, start router construction, and wait for the request to finish before calculating.

## What This Does Not Mean

Building a router does not edit or publish the dataset.

## How To Use This

Record the dataset and wait for completion before interpreting results.

## Example

A large city network takes longer to prepare than a small jurisdiction network.

## Assistant Guidance

Ask which dataset and router status are involved.
