# What is a Walksheds scenario?

## Short Answer

A scenario is a saved snapshot of an origin, profile, travel budget, settings, and resulting reachable network.

## Significance

Multiple scenarios can be overlaid to compare profiles, data, departure times, or hypothetical conditions.

## What This Means

Save named scenarios and compare their coverage and statistics. Comparisons can vary profiles, datasets, departure times, or edited attributes, but remain dependent on existing network geometry.

## What This Does Not Mean

A scenario is a model, not a guarantee that an improvement will produce the same result in practice.

## How To Use This

Keep the origin, budget, settings, and changes consistent when comparing scenarios.

## Example

A planner compares current conditions with a scenario in which curb ramps are present.

## Assistant Guidance

Label hypothetical changes and report assumptions.
