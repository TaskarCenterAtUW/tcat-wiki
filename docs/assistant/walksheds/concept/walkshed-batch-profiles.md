# How do profiles work in Walksheds batch requests?

## Short Answer

A batch request applies configured profiles, budgets, and cost settings to each input location.

## Significance

Profile differences affect reachability comparisons.

## What This Means

Record every profile parameter used for a batch.

## What This Does Not Mean

Batch options necessarily match all interactive controls.

## How To Use This

Verify slope, curb, street, and budget settings before running.

## Example

A pedestrian and wheelchair profile are run for the same facility coordinates.

## Assistant Guidance

Ask which profile fields the current batch interface supports.
