# How should an agency cite OS-CONNECT or TDEI data?

## Short Answer

Cite the specific OS-CONNECT or TDEI dataset, publisher or project group when relevant, release or version, date accessed, geographic scope, and format used. Link to the official dataset or documentation when a stable source is available.

## Significance

Complete citations let readers reproduce an analysis and understand which release and scope support its claims. They also prevent a current or local result from being mistaken for a timeless or statewide statement.

## What This Means

- Record dataset name, identifier or version, release date, access date, scope, and format.
- Cite the source documentation and any transformations or joins.
- State important quality, coverage, profile, or freshness limitations.

## What This Does Not Mean

A citation does not prove that the data are complete, authoritative for every use, or current in the field. Citing OS-CONNECT does not imply that TDEI, OpenStreetMap, or downstream products contain the same version.

## How To Use This

Use the dataset metadata as the primary citation source and keep a copy of the release details with the analysis. Ask the steward for a canonical identifier when the portal presents ambiguous names or versions.

## Example

An agency report names the OS-CONNECT release, geographic area, access date, format, and processing steps used to create its pedestrian-accessibility map.

## Assistant Guidance

Do not invent a citation format or identifier. Ask which dataset and release were used, cite the available official metadata, and abstain from claiming reproducibility when those details are missing.
