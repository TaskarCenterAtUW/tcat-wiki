# What is a project group in TDEI?

## Short Answer

A TDEI project group is a managed context for members, roles, services, datasets, and related workflows.

## Significance

The active project group determines which portal resources and permissions the user sees.

## What This Means

Users can belong to multiple groups, switch the active group, and copy its unique Project Group ID. Group members and Points of Contact have different permissions.

## What This Does Not Mean

A project group does not automatically make its datasets public or grant every member publishing rights.

## How To Use This

Confirm the active group before managing members, services, datasets, or jobs.

## Example

A user switches from one project group to another before opening its datasets page.

## Assistant Guidance

Ask for group name, ID, active context, and role when diagnosing access.
