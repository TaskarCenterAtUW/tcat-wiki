# What is a released dataset in TDEI?

## Short Answer

A released dataset in TDEI is a version made available through the system's release and visibility process for its intended audience. It is distinct from a private project dataset or an in-progress edit.

## Significance

Release status gives users a defined version and access boundary for viewing, downloading, and citing data. It also helps separate work under review from data presented for broader use.

## What This Means

- Check the dataset name, version, scope, release status, and validity information.
- Use the released version appropriate to the planning or analysis question.
- Record the release details and access date when using the data.

## What This Does Not Mean

Released does not mean complete, error-free, current in the field, or authoritative for every decision. A released dataset does not imply that private project data or every downstream product has the same content.

## How To Use This

Use the TDEI release and dataset metadata as the source of truth, and distinguish released data from project or draft data in reports and workflows.

## Example

An analyst selects a released OSW dataset for a planning map, records its version and scope, and cites it separately from a private workspace used for later edits.

## Assistant Guidance

Ask which dataset and release the user means. Cite the TDEI metadata, do not treat release status as a guarantee of accuracy or authority, and abstain when visibility or version is uncertain.
