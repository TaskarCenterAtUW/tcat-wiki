# How should I choose a TDEI dataset version?

## Short Answer

Choose by exact name, geographic scope, version, source lineage, and update date rather than place name alone.

## Significance

Similar names can represent different jurisdictions, extracts, or releases.

## What This Means

Confirm the version and scope before analysis or editing.

## What This Does Not Mean

A matching name does not prove that the dataset covers the intended area or is current.

## How To Use This

Compare metadata and record the selected dataset ID.

## Example

A user distinguishes a city, UGA, county, and completed project dataset before downloading.

## Assistant Guidance

Ask which scope and purpose the user needs.
