# How do I download an OS-CONNECT dataset from TDEI?

## Short Answer

Sign in to TDEI, open Datasets, choose All Released Datasets, filter for OSW and the OS-CONNECT project group, select the intended dataset, and download it in the available format.

## Significance

The workflow provides access to released pedestrian-network data without editing the source. Checking the full dataset name prevents downloading the wrong jurisdiction or version.

## What This Means

Use the dataset filters, inspect the name and version, open the action menu, choose Download, select the format, and confirm the download.

## What This Does Not Mean

A matching place name does not guarantee the correct geographic scope or latest version. Search results can contain similarly named datasets.

## How To Use This

Confirm the project group, jurisdiction suffix, dataset version, release status, and update date before downloading. Keep the selected format with the downloaded file.

## Example

A user filters released OSW datasets for the OS-CONNECT project group, chooses the correct city or UGA dataset, and downloads it as OSW.

## Assistant Guidance

Ask for the intended jurisdiction, version, and format. Do not assume that the first search result is correct.
