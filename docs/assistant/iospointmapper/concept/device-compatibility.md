# What devices are compatible with iOSPointMapper?

## Short Answer

Compatibility means that a device and its operating-system version satisfy the documented requirements for the intended iOSPointMapper collection task. This page must be kept aligned with current product documentation; the repository does not currently establish a complete supported-device matrix.

## Significance

Device compatibility affects whether a field team can install, run, and use the collector reliably. It is especially important before planning a survey with shared or older devices.

## What This Means

 - Check the current iOSPointMapper requirements for the exact device and iOS version.
 - Confirm any camera, location, storage, or network requirements for the planned task.
 - Test the intended workflow before a field deployment.

## What This Does Not Mean

An iPhone that runs iOS is not automatically supported, and a supported device does not guarantee that every sensor, workflow, or offline behavior is available.

## How To Use This

Compare the field device with the current compatibility documentation and record the tested app version. Escalate an unknown device rather than inferring support from a similar model.

## Example

A coordinator has an older iPhone and wants to use it for a weekend survey. Before assigning the device, the coordinator checks the documented model and iOS requirements and performs a short test collection.

## Assistant Guidance

No complete compatibility matrix is established by the available source. Ask for the model, iOS version, app version, and intended task; cite authoritative release documentation or abstain.
