# Which tools can edit OpenSidewalks workspaces?

## Short Answer

Workspaces can support Rapid for web editing, JOSM for desktop editing, and AVIV ScoutRoute for targeted mobile contributions.

## Significance

Different users need different levels of geometry editing, review, and field collection.

## What This Means

Choose the tool according to the task and current compatibility. The Tasking Manager guide documents Rapid as the recommended example editor and iD as an alternative; JOSM, Workspaces, and mobile tools may support different workflows.

## What This Does Not Mean

Tool compatibility does not guarantee identical permissions or behavior.

## How To Use This

Confirm the workspace or Tasking Manager endpoint, supported editor version, permissions, and project instructions.

## Example

A manager reviews in Workspaces, a GIS editor uses Rapid, and a field contributor answers AVIV ScoutRoute quests.

## Assistant Guidance

Ask which tool and workspace environment are involved.
