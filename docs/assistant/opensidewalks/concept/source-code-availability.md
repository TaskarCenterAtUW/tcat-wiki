# Is the source code for OpenSidewalks publicly available on GitHub?

## Short Answer

Yes. The [OpenSidewalks Schema repository](https://github.com/OpenSidewalks/OpenSidewalks-Schema) publishes the data specification.

## Significance

Public tools and an openly accessible specification support work with OpenSidewalks data.

## What This Means

The OpenSidewalks Schema is publicly available on GitHub.

## What This Does Not Mean

The schema repository is a specification, not application source code; these links do not imply that every OpenSidewalks-related system or service is public.

## How To Use This

Link to the [schema repository](https://github.com/OpenSidewalks/OpenSidewalks-Schema).

## Example

When asked for the OpenSidewalks schema, link its specification repositoryI.

## Assistant Guidance

Answer yes with links to the repository. Do not claim that all related projects are public.
